# pt-tools

## Introduction

An automation tool for private tracker sites: it downloads free torrents from RSS feeds, collects statistics and login status from every site, manages qBittorrent and Transmission in one place, and can be queried and controlled from QQ and Telegram.

## Features

- RSS downloads filtered by discount, size and keywords, with a free-space check before every push
- Multi-site search, statistics and a daily report
- Check-in and login keep-alive reminders
- Seed boosting: adds free torrents that match your rules and removes them by seeding time, ratio and more
- One place to manage qBittorrent and Transmission
- Queries and control from QQ and Telegram
