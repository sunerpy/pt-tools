> **No programming experience?** That is fine. Install the [PT Tools Helper browser extension](guide/browser-extension.md) (in Edge, from [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/pt-tools-helper/pgicnjkmgenmjfhlclodbpbedjmojbea), which keeps it up to date; in Chrome, download the zip from [GitHub Releases](https://github.com/sunerpy/pt-tools/releases) and load it by hand; for Firefox, see the browser extension page), collect the site's pages in one click and submit them.
