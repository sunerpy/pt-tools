# 种子搜索

「下载 → 种子搜索」在各站点上搜种子，挑一个推送到下载器。有两种搜法：

- **关键字搜索**：输入关键字后回车，结果是一张表，和 0.48.0 一样。
- **按条目搜索**：打字时从下拉里选一部电影或剧集，搜这个条目在各站点上的资源：按质量档案打分，同一个资源合成一张卡，剧集写明能补上哪几集。

按条目搜索、结果里的解析标签与「筛选」，以及不要的种子[拉黑](#拉黑)、不免费的种子[等免费](#等免费)再下，是 1.0 预览版加的。

## 关键字搜索

输入关键字后回车或点「搜索」。不选站点时搜所有启用的站点，也可以在下面一排只选几个；支持分类的站点各有一枚按钮，按站点自己的分类筛。一次搜索最多等 30 秒，没回应的站点写在「没返回的站点」里，不影响其他站点的结果。

| 工具栏                       | 说明                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| 全部、电影、剧集、动漫、音乐 | 按种子的分类筛；站点没给分类的种子另外计数，可以选择一并显示                                     |
| 仅免费                       | 只看免费的种子                                                                                   |
| 筛选                         | 按标题解析出的分辨率、来源、制作组等筛，见下文「筛选」                                           |
| 排序                         | 按做种数、下载数、完成数、大小、发布时间或站点排                                                 |
| 列设置                       | 选择表格显示哪些列                                                                               |
| 保存搜索                     | 把关键字、站点、排序、分类与「仅免费」存下来，列在下面「已保存的搜索」里，点一下按存下的条件重搜 |
| 最近搜索                     | 搜索框右边的按钮，列出最近 8 次搜索，点一条重搜                                                  |

每一行的标题下写着解析出的信息：分辨率、来源、平台、编码、HDR、制作组与中字，和站点给的分类、H&R。点「推送到下载器」选下载器、保存目录、分类与标签后推送；推送照常经过磁盘空间保护与站点做种容量的检查。剧集的种子可以点「追剧」，从这个种子开始追（见[追剧与订阅](media-subscribe.md#从一个种子开始追)）。每行最后的「更多」里有「等免费」与「不要」，见下文[等免费](#等免费)与[拉黑](#拉黑)。

## 按条目搜索

### 选一个条目

在输入框里打至少 2 个字，停半秒以后，下拉里列出 TMDB 上对得上的剧集与电影（各取前 5 个），写明年份、类型以及是否已经订阅、已经入库。用鼠标点，或者用上下键选中后回车，这个条目就成了输入框里的一个标记，开始按条目搜；没选候选时回车，仍按关键字搜。

也可以在「媒体 → 探索」的卡片上点「搜资源」，带着这个条目打开这一页。按条目搜要用 TMDB：发布的版本内置了 TMDB API Key；自己从源码编译的要先在[媒体识别](media-recognize.md#tmdb-api-key)里填。

条目标记右边的 × 去掉条目，回到关键字搜索，输入框里写回上一次关键字搜索的关键词。按条目搜时再在输入框里打字，只在结果里按标题筛，不会重新搜。

### 搜什么、怎么对

搜法和订阅的主动搜索一样：先用英文名或原名搜（电影加年份，剧集加季，如 `The Last of Us S02`），再用中文名搜；这一季已经订阅时用订阅自己的名字与别名。所有启用的站点都搜，一次最多等 60 秒。

搜到的种子按订阅的规则对条目（名字或 IMDb 编号、年份、季，见[追剧与订阅](media-subscribe.md#怎么找资源)），对不上的默认不显示，结果最后一行写着有几条；点它以后列出来，并写明为什么对不上。订阅写了标题包含、标题排除时，不合这两项的种子算不符合档案。

按条目搜只读：不建订阅、不推送、不写订阅的运行记录，也不改订阅的设置。

### 左栏

左栏是这个条目：海报、年份与类型，订阅了的写明在追、锁住的版本；点「条目详情 ›」打开这个条目的[详情页](media-detail.md)。

- **季**：剧集可以换季，默认是最新一季。
- **每集格子**：一格一集，颜色是这一集现在的情况：已入库（绿）、下载中（蓝）、等锁住的版本（主色）、缺（橙）、未播出（灰）。下面一句话写明缺哪几集、哪几集在下载。点一格只看包含这一集的结果，再点一次取消。
- **档案**：默认用这一季订阅的质量档案，没有订阅或订阅没选档案时用设置里的默认档案；可以换一个，或者选「不按档案」。换档案只影响这一次的结果，不改订阅。
- **筛选**：见下文「筛选」。

视口窄于 1280 时左栏收起来，结果上方是一排条目信息和「筛选」按钮，点了从右边打开同样的内容。

### 结果卡片

结果上方写着有几条结果、合成了几组、几组符合档案，有站点没回应时写明有几个，鼠标移上去看各站点的原因。排序可以选档案分（默认）、做种、体积、发布时间；不按档案时默认按做种排。

一张卡是一个资源：

- **左上的档案分**：按质量档案打的分换算成 0–100。分辨率、来源、编码都是档案里排第一的，并且有档案优先的 Remux、HDR、中字与偏好的制作组时是 100。不合档案的写「不符合」，不按档案时写「不按档案」。
- **右上**：能补上哪几集（如「能补上 E08」）；这几集已经在下载时写「E07 正在下载（HDSky）」；不符合档案时写原因，例如「不符合：分辨率 1080p 不在档案里」；电影已在下载或已入库时也写明。订阅锁了版本、这张卡不是那个版本时，下面加一行「不是锁定的版本（HHWEB）」。
- **标题下**：站点给的副标题、体积、发布时间与解析出的信息。
- **站点**：每一行是一个站点上的这个种子，写明做种数、优惠（免费写剩余时间）与 H&R 要求。第一行是首选，先后和订阅挑资源时一样（见[质量档案](media-subscribe.md#质量档案)的打分）。其余站点收在「另有 N 个站点」里，点开以后每个站点都能单独推送。

整组的集都已入库的卡默认折叠，点一下展开。

推送打开和关键字搜索一样的推送弹窗。推送时带上这个条目，种子下完以后整理入库按这个条目整理，不靠种子名识别（见[整理入库](media-library.md#哪些文件会整理)）。不符合档案的种子按钮写「仍然推送」，同样能推。弹窗里多一项「按条目建子目录」，默认跟订阅设置里的开关：打开时放进保存路径（没填时是每台下载器的默认保存路径）下按条目起名的一级子目录，见[按条目建子目录](media-subscribe.md#按条目建子目录)；读不到下载器的默认保存路径时照原来的保存路径推送并写明。

卡片右下角有「等免费」与「不要」，见下文[等免费](#等免费)与[拉黑](#拉黑)。

### 合并同一资源

搜索带右边的「合并同一资源」默认开着：不同站点上的同一个资源合成一张卡。站点给了 InfoHash 时，InfoHash 相同的合在一起；没给的，体积（精确到字节）、分辨率、制作组与集的范围都相同时合在一起。一个没有 InfoHash 的种子同时像好几个不同 InfoHash 的资源时，它单独一张卡，不并进任何一个。关掉以后一个站点上的一个种子一张卡。

## 筛选

关键字搜索在工具栏的「筛选」里，按条目搜索在左栏里，都按种子标题解析出的信息筛：

| 组               | 选项                                 |
| ---------------- | ------------------------------------ |
| 分辨率           | 2160p、1080p…，从高到低              |
| 来源             | WEB-DL、BluRay、Remux…               |
| 平台             | 流媒体平台，如 Netflix、腾讯视频     |
| HDR              | HDR10、杜比视界…                     |
| 制作组           | 按种子数从多到少                     |
| 中字与优惠       | 有中字、免费、无 H&R                 |
| 编码、季集、站点 | 按条目搜索时收在左栏的「更多筛选」里 |

同一组里选几个是「或」，组与组之间是「且」。每个选项后面的数，是按其他组现在的选择还剩几条：勾上一个选项不会让同一组的其他选项变成 0。数是 0 的选项不能勾。一组都没有选项时（例如结果里没有写平台的）这一组不显示。关键字搜索的「筛选」作用在分类与「仅免费」筛过的结果上，重新搜索时清空。

## 拉黑

不想要的种子（假种、音画不同步、画质差）点「不要」拉黑，可以写一句原因。拉黑以后订阅不再选它：RSS 送来的与主动搜索搜到的都跳过，运行记录里写「已拉黑：原因」。按站点与种子编号认，同一个资源在别处重新发布的种子不算；删了订阅再建，拉黑照样有效。

| 在哪里点                                     | 拉黑哪些                                                   | 对哪些订阅生效                                                |
| -------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| 按条目搜索的卡片「不要」                     | 这张卡上的全部种子（同一个资源在几个站点上的种子一起拉黑） | 只对这个条目（剧集是这一季）                                  |
| 关键字搜索每行「更多 → 不要」                | 这一个种子                                                 | 所有订阅                                                      |
| 追剧详情「下载过的种子」每行「不要这个种子」 | 这一个种子                                                 | 这个订阅的条目，见[追剧与订阅](media-subscribe.md#拉黑的种子) |

按条目搜索的卡片「不要」：这一季有订阅时还能勾「以后也不要这个制作组」，把首选种子的制作组加进订阅的标题排除词。拉黑的种子默认不显示，结果最后一行写「已拉黑 N 条」（只有一条时写出它的标题与原因）；点「已拉黑 N 条」把它们灰着显示在最后，每个站点一行都有「移出黑名单」，整张卡都拉黑了时卡片右下角还有「全部移出黑名单」。

关键字搜索里拉黑的种子仍然显示，标题下标「已拉黑」，「更多」里换成「移出黑名单」。全部拉黑的种子列在「追剧与订阅」页的「拉黑的种子」里，写明作用于哪个条目、原因与时间，也能在那里移出。

## 等免费

种子现在不免费，想等它免费了再下：按条目搜索的卡片右下角点「等免费」（用卡上第一个能等免费的站点上的种子），或者关键字搜索每行「更多 → 等免费」。打开的是推送弹窗的「等免费」模式：选一个下载器，填保存路径、分类、标签（同推送），再选等多久（1–30 天，默认 7 天）；没有「添加后立即开始」。

后台每 5 分钟看一次到点的种子，读种子详情页上现在的优惠：

- 免费了，而且免费剩余时间超过「免费期结束前提前处理」（见[配置说明](../configuration.md#免费结束管理)，至少 5 分钟；永久免费的不看这一条）：推送到选的下载器，照常经过磁盘空间保护与站点做种容量的检查；免费结束时没下完会暂停。发一条「等到免费了，已推送」的通知。种子在建的时候就是免费的，建好马上就推。
- 还不免费、免费剩余时间不够、看不出免费到什么时候，或者推送时被磁盘空间保护、站点做种容量挡下：30 分钟后再看。
- 读不到优惠、种子文件没下载下来、推送出错：1、2、4、4 小时以后再试；连续 5 次都这样就不再等，发一条通知，写明最近一次的原因。
- 到期时仍不免费：不再等，发一条「等免费到期了」的通知。

只有读得了种子详情的站点能等，读不了时按钮是灰的。在等的最多 200 条，同一个种子同时只能等一条。通知发给所有启用的通知通道，事件与变量见[消息模板](notify-channels.md#消息模板)。

「下载 → 等免费」页列出每一条：推到哪个下载器、现在怎样（等免费中、已推送、到期了、不再等、已取消）、上一次看到的情况、下次什么时候看、看过几次。在等的可以「改到期」（要晚于现在，最多从现在起再等 30 天）或「取消」。最多列出最近 500 条。

## 手机

手机上按条目搜索：输入框下面一排是季、档案与「筛选」按钮；条目卡上是海报与每集格子（点名字打开条目详情），结果卡的内容和桌面一样，竖着排，卡片最下面左右两半是「等免费」与「不要」。筛选从底部弹出，选好以后点「看 N 条结果」才生效，直接关掉不改；手机上的优惠还可以选 50%。站点没回应时概况下面单独一行写明，点它看各站点的原因。

## 常见问题

**打字时没有候选**：TMDB 没配好或连不上时不弹下拉，回车照常按关键字搜。自己编译的版本先在[媒体识别](media-recognize.md#tmdb-api-key)里填 TMDB API Key。

**按条目搜结果很少**：先看最后一行「对不上这个条目的 N 条」，点开看原因；名字和 TMDB 上的写法不一样时，在[媒体识别](media-recognize.md)里加识别词。没有订阅的条目只用 TMDB 上的名字搜，可以先用关键字搜试试站点上种子的写法。

**档案分是 0 或写「不符合」**：卡的右上写着原因；换一个档案或选「不按档案」看看，不会改订阅。

**等免费一直没有推送**：在「下载 → 等免费」页看那一条的说明，写着上一次看到的优惠（例如 `还没免费（现在是 50%）`）或没推成的原因。推送被磁盘空间保护挡下时，空出磁盘空间以后下一次检查会再推。
