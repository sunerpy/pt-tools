# 条目详情与订阅日历 <Badge type="tip" text="1.0 预览版" />

条目详情把一部电影或剧集在 TMDB 上的资料和它在你这里的情况放在一页：库里有几集、在做种的种子、订阅、媒体服务器里有没有，每一集入库了没有，下载过哪些种子；不要了的，在这里连库里的文件、种子与订阅一起删。订阅日历按天列出订阅的剧集每一集哪天播出、电影哪天上映，入库了没有；每天还可以把今天的更新推送到通知通道。

两者都用 TMDB 的数据：发布的版本内置了 TMDB API Key，不用填；自己从源码编译的要先在[媒体识别](media-recognize.md#tmdb-api-key)里填。

## 打开条目详情

能点进条目详情的地方：

- 「媒体 → 探索」：点海报或名字。
- 「媒体 → 追剧与订阅」：点订阅的名字，剧集打开订阅的那一季。
- 「媒体 → 整理历史」：点「条目」列里识别出的名字。
- 「下载 → 种子搜索」按条目搜索时：左栏的「条目详情 ›」，手机上点条目卡的名字（见[种子搜索](torrent-search.md#按条目搜索)）。
- 「媒体 → 日历」：点一项。
- 条目详情的「推荐」：点海报，打开那一部。

页头的面包屑写明从哪一页进来，例如「媒体 / 追剧与订阅 / 长夜将尽」，点中间那段回到那一页。TMDB 上没有这个条目、或者读 TMDB 出错时，页面写明原因，可以重试。

## 资料与动作

最上面是背景大图：海报、名字、原名与年份（剧集写几季几集，电影写片长），类型、出品国家、每集片长、状态（连载中、已完结、已上映……），TMDB 评分与评分人数，简介，导演与前几位主演。桌面上还有 IMDb、TVDB 的链接。

| 动作                      | 说明                                                                                                                                    |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 搜资源                    | 打开种子搜索，按这个条目搜各站点，剧集带上正在看的那一季                                                                                |
| 追剧、订阅                | 没有订阅时打开订阅的弹窗，剧集追正在看的那一季；已经订阅时是一个菜单：打开追剧详情、暂停或恢复，正在看的这一季没订阅时还有「追第 N 季」 |
| 在 Jellyfin 播放          | 媒体服务器里有这一部时才有（写的是服务器的名字）：在新标签页打开服务器上的这一部。有几台服务器时打开第一台有的                          |
| 重新刮削                  | 库里有这个条目时才有：按媒体库现在的刮削设置重写它的 NFO 与图片，同[整理历史](media-library.md#整理历史)里的「重新刮削」                |
| 删除                      | 库里有文件、有关联的种子或订阅时才有：打开[删除弹窗](#删除一部片)，电影删整部，剧集删正在看的这一季                                     |
| 更多 → 在 TMDB 打开       | 在新标签页打开 TMDB 上的这一页                                                                                                          |
| 更多 → 复制 TMDB 编号     | 把 TMDB 编号复制到剪贴板                                                                                                                |
| 更多 → 手动整理到这个条目 | 打开[手动整理](media-library.md#手动整理一个文件或目录)，条目已经填好，填上源路径就能整理                                               |

手机上「重新刮削」「删除」也收在「更多」里，「更多」在大图的右上角；「在 Jellyfin 播放」在「你的 NAS 上」白卡的底部。

## 你的 NAS 上

四行写这个条目在你这里的情况（第 4 行要先[加媒体服务器](media-library.md#媒体服务器)并同步过[索引](media-library.md#索引)）：

- **库里**：剧集按季写入库了几集，例如 `库里 S01 12/12 · S02 6/12`，下面是媒体库、文件数与体积；电影写入库文件的版本（分辨率与制作组）。库里没有时写「库里没有」。每天巡检发现库里的文件不见了时，下面一行改用警示色写哪一集（`S02E05 的文件不见了`，几个时写 `S02E05 等 2 个文件不见了`），后面是「处理」「忽略」（见[库里的文件不见了](media-library.md#库里的文件不见了)）。
- **做种**：在做种的种子数。有 H&R 要求、做种时间不够的，写有几个、其中最快做够的还差多久（例如 `1 个 H&R 还差 2 天`）；都够了写最低的分享率。
- **订阅**：订阅的状态与季（`追剧中 · 第 2 季`、`已暂停`、`待确认`、`已完成`），下面是锁住的版本，没开版本锁时写明；没订阅时写「没有追剧」或「没有订阅」。
- **媒体服务器**：服务器里有没有这一部，剧集写有几集（`Jellyfin 已入库 17 集`），下面是上次同步索引的时间。pt-tools 整理进库的集在服务器里没了时，用警示色写哪一集（`S02E03 在服务器里被删了`，几集时写 `S02E03 等 3 集`），后面是「处理」「忽略」：「处理」打开只选这几集的[删除弹窗](#删除一部片)；忽略以后这几项一直没再出现时都不再提示（见[服务器里没了的片子](media-library.md#服务器里没了的片子)）。有几台服务器时，先写有这种问题的那一台，再是有这一部的。

桌面上这一块在大图右边，窗口窄时放到大图下面；手机上在大图下面的白卡里。

## 季与集

剧集才有这一块。

- **季 tab**：每一季写已入库几集、共几集（`6/12`），开了[算作已入库](media-library.md#算作已入库)时服务器里有的集也算；特别篇排在最后。打开时选链接里指定的季，没有指定时选订阅的那一季，都没有时选最新的已经有集的一季。换季时地址跟着换，刷新或分享链接时还是这一季。
- **图例**：这一季每种状态各几集。
- **集卡**：剧照、集号与集名、播出日（今天播出的写「今天」，按播出时间追剧的带上播出时刻，最后一集写「季终」，TMDB 没给日期的写「播出日期未定」）、状态与说明：

| 状态     | 说明                                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `已入库` | 写入库文件的版本与体积；库里的文件不见了的写 `库里的文件不见了`，媒体服务器里没了的写 `Jellyfin 里没有了`，右上角是「处理」「忽略」；整理记录里没有、[算作已入库](media-library.md#算作已入库)的写 `Jellyfin 里有` |
| `下载中` | 写下载进度与还要多久，下面有进度条                                                                                                                                                                                 |
| `等版本` | 写锁住的版本；点「看版本」打开这一季的按条目搜索，看各站点有哪些版本                                                                                                                                               |
| `缺`     | 已经播出、库里没有，写播出了几天；点「搜资源」打开这一季的按条目搜索                                                                                                                                               |
| `还没播` | 下一集写播出后几小时开始搜（按播出时间追剧时）；今天播出、但未到播出时刻的集也算这一种                                                                                                                             |
| `不追`   | 起始集以前的与跳过的集                                                                                                                                                                                             |

已入库、媒体服务器里有这一集时，剧照上有播放按钮，点它或点这张集卡在服务器里打开这一集。

状态和追剧详情里每一集的格子一样（见[追剧与订阅](media-subscribe.md#每一集)）；这一季没订阅时，按 TMDB 上的集与库里的情况算，不会因此建订阅。开头连着都已入库的集收成一行（`E01–E20 · 20 集都已入库`），点「展开」全部列出，再点「收起」：手机上超过 3 集就收，桌面上一季超过 24 集才收。

## 这一季的种子

列出和这个条目有关、现在还在下载器里的种子：推送时带了这个条目的（订阅、按条目搜索推送的）、订阅下载的、整理进库的。不在下载器里的不列。剧集只列正在看的那一季的种子（认不出是第几季的也列），电影这一块叫「这部片的种子」。

每一行写站点，季与集、版本与体积，下载器，状态（做种中、下载中、暂停、出错；下载器连不上时是「没读到」），分享率与做种多久（下载中的写进度），最后是能不能删。能不能删按[自动删种的保护规则](auto-cleanup.md#保护规则)判断，两处用的是同一套：标题右边写着现在开着哪几条（例如 `删除时按这几条保护：下载中、最短保种 24 小时、H&R、保留与保护标签`），鼠标移到受保护的那一格上能看到完整的原因。

| 写的是                       | 意思                                             |
| ---------------------------- | ------------------------------------------------ |
| 可以删                       | 没有命中保护规则                                 |
| H&R 已满足                   | 有 H&R 要求，做种时间已经够了                    |
| H&R 还差 2 天                | 有 H&R 要求，做种时间不够，写还差多久            |
| 受保护：H&R 要求不明         | 站点标了 H&R，但不知道要做种多久                 |
| 受保护：下载中               | 正在下载或校验（打开了「保护下载中的种子」时）   |
| 受保护：加进来不到 24 小时   | 还不满最短保种时间                               |
| 受保护：标签 pt-tools-keep   | 带保留标签或保护标签                             |
| 受保护：读不到保护规则       | 读不到全局设置，分不清哪些受保护，一律当作受保护 |
| 下载器没读到，不知道能不能删 | 读不到这台下载器                                 |

每行最后的「更多」：

- **在下载器里打开**：打开「下载 → 下载器 Web UI」，选中这台下载器并按这个种子筛选。
- **删除这个种子**：打开[删除弹窗](#删除一部片)，只勾这一个种子，库里的文件不勾，订阅保留。
- **不要这个种子**：拉黑这个种子，只对这个条目生效：订阅以后不选它，下载器里的种子不动（见[拉黑](torrent-search.md#拉黑)）。不知道站点上种子编号的不能拉黑，没有这一项。

手机上点一行，从底部弹出这几项。

## 删除一部片

不要了的电影或剧集的一季，在条目详情里删：大图里的「删除」（手机在「更多」里）删整部电影或正在看的这一季；种子行的「删除这个种子」与问题的「处理」打开同一个弹窗。弹窗先列出会动到的东西，自己勾要删的，底部那一行跟着勾选写这次会做什么（例如 `将删除 6 个库文件、1 个种子（连数据），暂停追剧`），点「删除」才删。

**删除库里的文件**：pt-tools 整理进库的文件与它们的整理记录，默认勾上。说明写几个文件、多大、整理方式，点「看文件」列出每一个。删的规则同[整理历史](media-library.md#整理历史)里连文件删除记录：

- 只删确认还是当初整理出的那个文件；换成了别的、改过的留着，只删记录。库里已经没有的，删的是记录。
- 移动整理的文件是唯一的一份，这里不删，写明原因。
- [导入的已有文件](media-library.md#导入已有的媒体库)导入前就在库里，删了就没有了：另外勾「也删导入前就有的文件」才删。
- 硬链接、软链接与复制出来的文件删掉以后，种子里的数据不受影响。

**种子**：和这一季（这部电影）有关、还在下载器里的种子，每台下载器上的每个种子一行，同一个种子在两台下载器上就是两行，各自判断。

- 能删的默认勾上，右边选「连数据一起删」（默认）或「只删种子」。同一台下载器里还有别的种子（这次不删的）用着同一份数据时，只删种子、保留数据，这一行写明是哪个种子在用，不能改。
- 受保护的（见上一节的保护规则）写着原因，默认不勾；要删的话勾右边的「仍然删除」，每个种子单独勾。
- 种子里还有这次没选的集时（例如整季包、只删其中几集），默认不勾，写明还有哪几集。

**订阅**：有这一季（这部电影）的订阅时才有这一块。

| 选项         | 说明                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| 暂停追剧     | 默认。不暂停的话，台账会把删掉的集当成缺的，再去下一遍；完成了的电影订阅不会再找，不动它 |
| 删除订阅     | 以后不再找这一季                                                                         |
| 保留，继续追 | 只删这次选的文件和种子，订阅照常                                                         |

不是追剧的订阅（电影与没开追剧的剧集）写「暂停订阅」「保留订阅」。订阅原来就暂停了、是待确认的（豆瓣想看建的），或是完成了的电影订阅时，暂停什么也不会做：「暂停」那一项写明为什么不用暂停（例如 `不用暂停：已经暂停了`），默认选保留。

点「删除」以后先处理订阅，再一台台下载器删种子，最后删库里的文件，每一步单独写结果：做成的打勾，没做成的写原因，没做成的不影响已经做完的。几点说明：

- 删种子时不按弹窗里看到的：重新读下载器、重新算保护和共用数据。打开弹窗以后才变成受保护的种子照样不删，结果里写明；下载器里已经没有的算做成了。
- 连数据删种子时，这个种子整理出、这次没勾删的硬链接留着：打开了「删种时一并删除入库链接」也不删（见[与自动删种的关系](media-library.md#与自动删种的关系)）。
- 删了库里的文件与整理记录以后，这几集「库里的文件不见了」「在服务器里被删了」的问题改成已处理。「处理」打开时只选有问题的那几集，最上面写着要处理的是哪几个问题。
- 删除和自动删种、刷流删种一个一个来，不会同时删同一个种子；每次删除写进日志（`[媒体库] 网页上删除 …`）。
- 网页上才有删除，手机 App、MCP 与机器人里没有。

## 演职员与推荐

**演职员**：导演在前，后面是演员，带头像、名字与饰演的角色。桌面上点「全部 N 位」展开成几行，再点「收起」；手机上横着滑。

**推荐**：TMDB 按这一部推荐的电影或剧集（最多 12 个），标出库里有的（`已入库`）与已经订阅的（`已订阅`），点海报打开那一部的详情。

演职员、各季的列表、推荐或某台下载器没取到时，其余部分照样显示，上方写明哪几部分没取到，点「重试」再取一次。没有推荐、没有演职员时这一块不显示。

## 订阅日历

「媒体 → 日历」按天列出订阅的剧集每一集哪天播出、电影哪天上映。暂停的订阅不列；豆瓣建的待确认订阅确认以前也不列。剧集按 TMDB 上每一集的播出日期排，TMDB 上没有播出日期的集排不进来；电影按 TMDB 的上映日期。

每一项写名字、季与集（`S02E03`，电影写「上映」）与状态，状态同条目详情的集卡（月视图里是圆点的颜色）。按播出时间追剧的，周视图与手机上写播出时刻，月视图里鼠标移到那一项上能看到；今天播出、未到播出时刻的写 `还没播`。

- **月视图**：一格最多列 3 项，多的写「还有 N 项」，点了换成那一周的周视图。
- **周视图**：每天列出全部，带海报与集名。
- **手机**：按天列出有内容的天，今天写「今天」。

右上角切换月、周，左右箭头翻到上一段、下一段，「今天」回到今天；地址里记着视图与日期。点一项打开条目详情，剧集打开那一季。某个订阅读不到 TMDB 时，日历上方写明是哪一个，其余照样列出。

## 今日更新

在「媒体 → 追剧与订阅」最下面的「订阅设置」里打开「今日更新」，每天把今天播出的集与上映的电影推送到通知通道：

| 选项     | 说明                                                 |
| -------- | ---------------------------------------------------- |
| 今日更新 | 开关，默认关                                         |
| 推送时刻 | 默认 09:00，按服务器的时区，每 15 分钟一档           |
| 推送到   | 推送到哪些通知通道；不选时推送到上面「通知」选的通道 |

到点以后发一条「📺 今日更新 2026-11-03」，列出今天播出的每一集（订阅名与年份、季、集号与集名，按播出时间追剧的带播出时刻）与上映的电影，各写状态（`已入库`、`下载中`、`还没播`……）。

- 今天订阅里没有播出的集、也没有上映的电影时不发。
- 一个通道一天只收到一条，重启以后也不会重发；pt-tools 在推送时刻以后才启动的，当天照样会发。读不到 TMDB 时 10 分钟以后再试。
- 订阅的总开关关着时不推送。
- 按通道的静默时段延后，失败时自动重试；文字可以在[消息模板](notify-channels.md#消息模板)里改，事件是 `media.calendar.today`。

## 机器人与每日战报

- 在机器人里发 `/today`（也可以写 `/今日`），回复今天订阅里播出的集与上映的电影、各自入库了没有，最多列 30 项，多的到网页的日历上看。所有绑定了的账号都能用，见 [ChatOps 快速开始](chatops-quickstart.md)。
- [每日战报](user-stats.md#每日战报)多一行 `📺 昨日追剧：播出 N 集，入库 M 集`（战报统计当天时写「今日」）：统计的那一天订阅里播出的集，与其中现在已经入库的集。订阅的总开关关着、那天没有播出的集时没有这一行。
