# CookieCloud 导入

「站点 → CookieCloud 导入」从自建的 [CookieCloud](https://github.com/easychen/CookieCloud) 服务取回浏览器扩展同步上去的 Cookie，在本机解密，按站点地址挑出 pt-tools 站点能用的 Cookie，预览后写进站点。也可以打开定时同步，默认关闭。

## 开始前

- 需要一个在用的 CookieCloud：浏览器装了 CookieCloud 扩展，并同步到你自己的服务端。
- 在扩展里能看到服务器地址、用户 KEY（UUID）和端对端加密密码，pt-tools 里填同样的三项。
- pt-tools 只从服务端取回加密的数据（`GET <服务地址>/get/<UUID>`），用密码在本机解密；密码不发给 CookieCloud 服务端。
- 密码用与站点 Cookie 相同的密钥加密保存在本机；页面和接口都不显示它，只显示「已设置」。
- 只导入 pt-tools 站点地址能用的 Cookie，其他网站的 Cookie 不保存。

扩展的两种加密方式都支持：旧版的默认方式，和 0.3.0 起可选的 `aes-128-cbc-fixed`。

## 设置

| 项目             | 说明                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------- |
| 服务地址         | CookieCloud 服务端的地址，以 `http://` 或 `https://` 开头，不能带用户名密码、查询参数或 `#` |
| 用户 KEY（UUID） | 扩展里的用户 KEY                                                                            |
| 端对端加密密码   | 扩展里的密码；不填就保留原来的，「清除」会删除密码并关闭定时同步                            |
| 定时同步         | 打开后按间隔同步，只更新已经启用、Cookie 有变化的站点，不会启用新站点                       |
| 同步间隔（小时） | 1–168 小时，默认 24 小时                                                                    |

每次同步的结果写在设置下方的「上次同步」里。

## 导入

1. 点「读取 CookieCloud」：pt-tools 取回数据、在本机解密，列出能导入的站点、Cookie 的名字和站点的情况。不写任何东西，也不显示 Cookie 的内容。
2. 勾选要导入的站点，或者点「选中有变化的」（已经启用、Cookie 有变化的站点）。
3. 点「导入选中」并确认：选中站点的 Cookie 换成 CookieCloud 里的，尚未启用的站点会被启用；只改 Cookie 和启用状态，RSS 等其他设置不动。之后 pt-tools 刷新这些站点并检查一次登录状态，和浏览器扩展同步 Cookie 一样。

导入时 pt-tools 会重新取一次数据，不用预览时的结果。保存了新的服务地址、UUID 或密码后，上次读到的列表会清掉，要重新读取；读取或同步进行时改了这几项，这一次不写入。同时要 API Key 的站点，先在站点设置里填好 API Key 再导入。

站点的情况有三种：没有启用（导入后启用）、Cookie 有变化、没有变化（再导入也不写）。

### Cookie 怎么挑

pt-tools 按它访问这个站点用的地址的主机名挑 Cookie：

- 域名带点（如 `.hdsky.me`）的 Cookie 对这个域名和它的子域名都有效；不带点的只对同一个主机名有效。
- 路径不是 `/` 的、已经过期的不要。
- 同名的 Cookie 取域名最具体的那个。

只支持用 Cookie 登录的站点；只用 API Key 或 Passkey 的站点（如 M-Team）不在列表里。

## 接口

| 方法与路径                             | 说明                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `GET`、`PUT /api/cookiecloud/settings` | 读取或保存设置：`password` 以外整份保存，不认识的字段会被拒绝；`password` 不传时保留原来的，空串时清除 |
| `POST /api/cookiecloud/preview`        | 取回、解密并匹配，返回能导入的站点与 Cookie 名（不含 Cookie 的值）                                     |
| `POST /api/cookiecloud/import`         | `{"sites": [...]}`：导入选中站点的 Cookie，返回更新、没有变化、没找到和写入失败的站点                  |

都要求登录。
