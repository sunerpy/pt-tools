# AI 助手 <Badge type="tip" text="1.0 预览版" />

pt-tools 内置一个 AI 助手。接上一个大模型以后，可以在网页、手机 App 或者通知渠道（Telegram、QQ）里用自然语言问站点数据、下载器状态与抓到的种子，让它搜索种子、推送到下载器、管理订阅，识别种子标题、把下载完的电影与剧集整理进媒体库，也可以让它查看、修改 pt-tools 的配置。改动类操作每次都要你确认才执行，确认卡片写明改以前、改以后与可能的影响。网页上还可以接 [Voltip](#语音输入) 用说话代替打字。

助手在 pt-tools 后端运行，调用的是和 [MCP](mcp.md) 同一套工具，经 [App API](../reference/app-api.md) 执行：看到的数据、脱敏规则与 App 一样。任何 OpenAI 兼容的 Chat Completions 接口都能接，模型要支持工具调用（function calling）。

## 接上大模型

打开「系统 → AI 助手设置」：

1. 选服务商。选了预设会填好接口地址与常用模型；服务商下面写着有没有免费额度、要不要代理，「去申请 API Key」打开服务商申请 Key 的页面。
2. 填 API Key。
3. 选模型：点「获取模型列表」，pt-tools 用填好的地址与 Key 读服务商的模型列表，放进下拉框；也可以直接输入模型名。要选支持工具调用（function calling）的模型。
4. 点「测试连接」：pt-tools 发一条很短的消息，显示模型的回答与用时。
5. 打开「启用 AI 助手」，保存。

| 服务商                 | 接口地址                                                  | 模型                                                                  |
| ---------------------- | --------------------------------------------------------- | --------------------------------------------------------------------- |
| DeepSeek               | `https://api.deepseek.com`                                | `deepseek-flash`、`deepseek-v4-pro`                                   |
| 通义千问（阿里云百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1`       | `qwen3.7-plus`、`qwen3.8-flash`、`qwen3.8-max`                        |
| Kimi（月之暗面）       | `https://api.moonshot.cn/v1`                              | `kimi-k2.6`、`kimi-k3`                                                |
| 硅基流动               | `https://api.siliconflow.cn/v1`                           | 点「获取模型列表」选                                                  |
| Google AI Studio       | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-3.5-flash-lite`、`gemini-flash-latest`、`gemini-3.8-flash` 等 |
| Groq                   | `https://api.groq.com/openai/v1`                          | `qwen/qwen3.8-27b`、`openai/gpt-oss-120b`、`openai/gpt-oss-20b`       |
| OpenRouter             | `https://openrouter.ai/api/v1`                            | 点「获取模型列表」选                                                  |
| Ollama（自己部署）     | `http://<Ollama 所在主机>:11434/v1`                       | `ollama list` 里的模型名，不要 API Key                                |
| OpenAI                 | `https://api.openai.com/v1`                               | `gpt-6.1-sol` 等                                                      |

表里的模型名是 2026 年 10 月各家文档上的，以服务商控制台为准。

- 接口地址填到 `/chat/completions` 之前，不带查询参数。
- API Key 加密保存，只能改、不能读出来。换了接口地址又没填新 Key 时，保存会清掉存着的 Key：Key 只发给保存它时的那个地址。
- 代理留空时用环境变量 `HTTP_PROXY`、`HTTPS_PROXY`；也可以单独填 `http://`、`https://` 或 `socks5://` 代理。获取模型列表、测试连接与对话都走这个代理。从中国大陆访问 Google AI Studio、Groq、OpenAI 一般要代理：Google AI Studio 对中国大陆与香港的地址回 `User location is not supported`。
- pt-tools 在 Docker 里、Ollama 在宿主机上时，地址要写宿主机的地址，不是 `127.0.0.1`。
- 模型的推理内容（思考过程）脱敏以后在对话页上显示。DeepSeek、通义、Kimi 等按 `reasoning_content` 返回的，pt-tools 在后面的请求里回传给模型（带工具的请求要求回传）；OpenRouter、Groq、Ollama 等按 `reasoning` 返回的，以及写在回答开头的 `<think>…</think>`，只显示、不回传（有的服务商不认回传的字段，会拒绝整个请求）。

### 用免费额度

自己申请一个 Key，就能用这些服务商每天的免费额度。额度会调整，以服务商的页面为准：

| 服务商                 | 免费额度（2026 年 10 月）                                                    | 要知道的                                                        |
| ---------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Google AI Studio       | Gemini 的 Flash 等模型有免费额度，每分钟、每天限次数；有的模型每分钟只有几次 | 免费层的对话内容可能被 Google 用来改进产品；要代理              |
| Groq                   | 表里的三个模型免费，每个每天约 1000 次请求、20 万 token，每分钟 8000 token   | 每分钟的 token 少，要调好几次工具的问题会多等一会儿；一般要代理 |
| 通义千问（阿里云百炼） | 新开通的账号每个模型各有一份免费额度，用完开始计费                           | 在百炼控制台给模型打开「免费额度用完即停」就不会多花钱          |
| 硅基流动               | 模型广场里标着「免费」的模型可以免费用，有限速                               | 选支持工具调用的模型                                            |
| OpenRouter             | 名字带 `:free` 的模型免费，每天有次数上限                                    | 选支持工具调用的模型                                            |

小模型调工具常常不可靠。回答总是不调工具、编工具名或者参数写错时，换一个大一点的模型。

设置里还有三个上限：

| 设置                     | 默认    | 说明                                                 |
| ------------------------ | ------- | ---------------------------------------------------- |
| 确认等待                 | 10 分钟 | 改动类操作等你确认的时间，1 到 60 分钟，过了就不执行 |
| 每次回答最多调用几轮工具 | 8       | 1 到 20；到了上限就停下来，提示换个说法再问          |
| 会话保留                 | 30 天   | 更新时间早于这么多天的会话每天清理一次；0 表示不清理 |

### 上下文与压缩

对话越长，每次请求带上的历史越多。输入框里发送按钮左边的小圆环是这个会话的上下文用了窗口的多少：离压缩阈值不到 15 个百分点变黄，到了阈值变红。鼠标移上去（手机上点一下）看详情：上下文大约多少 token、窗口从哪儿来、什么时候自动压缩、本会话一共用了多少输入与输出 token。

| 设置                | 默认      | 说明                                                                                                       |
| ------------------- | --------- | ---------------------------------------------------------------------------------------------------------- |
| 上下文窗口（token） | 0（自动） | 0 表示按服务商模型列表报的长度，没报的按模型名估计，最多按 128K 算。填小一点会更早压缩，每次请求更省 token |
| 自动压缩            | 打开      | 上下文用到窗口的这个比例时，开始回答以前先让模型把前面的对话写成摘要                                       |
| 压缩阈值            | 80%       | 50% 到 95%                                                                                                 |

- 压缩时过程里写着「正在压缩上下文…」，压完对话里多一条提示（前面几条消息压缩成了摘要）。之后交给模型的是摘要加上它后面的消息；对话页上照旧能看到全部消息。
- 压缩过的会话，摘要以后至少又有 4 条消息（大约两轮对话）才会再自动压缩：窗口填得很小、系统提示与工具定义就占了大半时，不会每问一句压一次。
- 服务商因为上下文太长拒绝请求时，pt-tools 压缩一次再试。
- 关掉自动压缩以后，太长时从最早的消息丢起。
- 写摘要也要调用模型，用量算在这个会话里。服务商没有报用量时，上下文按字数估算，详情里写着「约」。

## 对话

打开「概览 → AI 助手」：左边是会话（上面的搜索框按标题找；按今天、昨天、近 7 天、更早分组；鼠标移到会话上，右边出现删除按钮，手机上一直在），右边是对话，输入框在对话下面。新对话里有几个推荐的问题，点一下填进输入框。可以这样问：

- 我的站点数据怎么样，哪个站分享率最低
- 下载器现在有多少在下载，剩余空间还有多少
- 最近 RSS 抓到了什么
- 搜一下 沙丘 2160p 的免费种子
- 把第二个推送到默认下载器
- 订阅《沙丘》第二季；我的订阅还缺哪些集
- 这个种子标题是什么片：`Dune.Part.Two.2024.2160p.WEB-DL.H265-ABC`
- 最近整理入库失败的有哪些，重新整理一下

回答一边生成一边显示：

- **过程**：回答上面是这次回答的过程，按发生的顺序排成一条时间线：每一段思考（模型给了推理内容时，一边生成一边显示）、调用的每个工具（工具名、参数与用时，点开看返回的数据），调了几轮就有几段。进行中最上面一行写着正在做什么，例如「正在查看站点数据…」。
- **自动折叠**：回答进行中过程展开；回答完折成一行（例如「已思考 · 调用了 3 个工具（2 轮） · 用时 12 秒」），点一下展开。等你确认的操作不折，卡片在过程下面、回答上面。
- 回答下面有复制按钮，写着这一轮用的模型与推理等级。

回答进行中可以点「停止」；同一个会话同时只回答一个问题，等它结束再问下一个。

### 选模型与推理等级

输入框下面有两个下拉框，每条消息都可以换：

- **模型**：默认是设置里的模型；点开时 pt-tools 读一次服务商的模型列表（10 分钟内用缓存），也可以直接输入模型名。打开一个会话时沿用这个会话最后一次选的。
- **推理等级**：默认、不思考、低、中、高，发给服务商的是 `reasoning_effort`（`none`、`low`、`medium`、`high`；默认是不带这个参数，用模型自己的）。各家认的不一样：服务商因为这个参数拒绝请求时，pt-tools 去掉它重试一次，会话里多一条「这个模型不认推理等级」的提示。

### 发图片与文本文件

点输入框下面的回形针选文件，也可以把文件粘贴或者拖进输入框。一条消息最多 4 个附件；只写附件不写字也能发。

| 种类     | 格式                                                                                           | 大小        |
| -------- | ---------------------------------------------------------------------------------------------- | ----------- |
| 图片     | PNG、JPEG、WebP、GIF（按内容认，SVG 不收）                                                     | 每张 5 MB   |
| 文本文件 | UTF-8 编码的 `.txt` `.md` `.log` `.json` `.csv` `.yaml` `.toml` `.ini` `.xml` `.nfo` `.srt` 等 | 每个 200 KB |

- 文本文件的内容先脱敏（同你写的文字：地址里的 passkey、Cookie、API Key 与长串都遮掉），再放进消息交给模型；以前消息里的文本文件在历史的字数上限以内照给，太长的只写一句占位。
- 图片只随这一条消息发给模型。之后再问，模型靠它之前的回答接着聊；要它再看一遍，就重新发图。模型不能看图时服务商会拒绝请求，提示里写着「这个模型可能不能看图」：换一个能看图的模型，或者去掉图片再发。
- 选了文件就开始上传，传了还没发的附件只有你看得到，一天以后清掉；发出去的附件跟着会话保存，删会话时一起删。PDF、压缩包、种子文件都不收。

你贴的种子下载地址会先换成「站点 X 的种子 Y」再交给模型，地址里的 passkey 不出 pt-tools；只认已配置站点的地址，磁力链接不收。

## 改动类操作要确认

暂停、继续、删除种子，推送种子到下载器，添加、暂停或恢复、立即搜索、删除订阅，整理进媒体库、重新整理，以及修改配置，这些操作执行以前，pt-tools 先按现状算一份预览，对话里出现一张确认卡片：

- 一句话写明要做什么，例如「暂停下载器「qb」里的「Dune.Part.Two…」（52.3 GB，做种中）」。
- 改动：每一项改以前、改以后，例如「状态：做种中 → 已暂停」「种子下载目录（download_dir）：/downloads → /data/pt」。密钥只写「已更新（不显示）」。
- 影响：可能带来什么，例如「删掉以后不能恢复」「会释放 52.3 GB」「RSS 任务按新设置重新加载」。

点「确认执行」才执行，点「拒绝」或者在确认等待时间里没有处理就不执行，助手会照实告诉你结果。预览读不到现状时（比如下载器连不上），卡片的影响里写明，确认以后照样执行；确定执行不了的（找不到这个种子、订阅），助手直接告诉你，不出现卡片。

- 模型看不到也设不了确认的参数，确认只能由你点。
- 一次回答里要做几件事时逐个确认：前一个有了结论，才出现下一个。
- 同一个操作只算一次：两个页面同时点确认，或者确认与超时撞在一起，只有一个结论算数，操作最多执行一次。
- 停止回答、重启 pt-tools 时，还在等确认的操作都作废。
- 执行的操作记在「ChatOps → 操作审计」里：通道是「AI 助手」，命令是工具名，触发用户是会话的属主（网页上是 `web:<用户名>`）。经助手推送的种子在任务列表里的来源是 `assistant_push`。

## 改配置

可以让助手查看、修改 pt-tools 的配置，例如：

- 把全局下载目录改成 /data/pt
- 停用下载器 qb2；把 qb1 设成默认下载器
- 给 hdsky 加一条 RSS，推到 qb1，关联「4K」这条过滤规则
- 打开 hdsky 的自动签到；签到时间窗改成 7 点到 9 点
- 失效种子扫描的通知改发到 Telegram 那个通道
- 新建一个只要中字的质量规则

助手用 `get_config` 看现状、`change_config` 改，第一次用以前先读内置的 `pt-tools-config` 技能（写明各类配置有哪些字段、怎么改）。每次改动都先出确认卡片，列出每一项改以前、改以后。改动交给网页上保存时用的同一个接口，校验、加密与热重载都和在网页上改一样，接口的报错（比如「默认下载器不能停用」）照实告诉你。

能改的有：全局设置、下载器、站点（启用、凭据、限速、刷流容量、H&R 做种要求、自动签到）、RSS 订阅、过滤规则、通知通道、消息模板、自动签到、每日战报、失效种子扫描、登录提醒、日志级别、刷流任务、转移做种规则、辅种、CookieCloud、CloakBrowser、媒体识别、整理入库、二级分类、媒体库、路径映射、监控目录、媒体服务器、订阅设置、质量规则、豆瓣想看、识别词与识别纠正。

- 密钥只写不读：密码、Cookie、API Key、Passkey、令牌、RSS 地址，以及通知通道配置里的令牌与地址，助手只看到「已设置」或空，可以写新值，读不回原文。你在对话里贴的长串会先被遮住再交给模型，所以 Cookie、Passkey 这类请到网页上填。
- 不能经助手改：登录密码、API 令牌、远程访问（设备与配对）、加密密钥、AI 助手自己的设置（服务商、接口地址、API Key、模型、代理、ChatOps 开关、语音输入）、ChatOps 绑定与管理员、qB 兼容入口。
- 谁能改：网页上一直能；通知渠道里只有管理员绑定能；App 里看令牌或设备的权限（配对的设备没有配置权限，读改不了配置）。
- 改动记在「操作审计」里，命令是 `change_config`，参数只记改了哪类配置、哪些字段，不记值。

外部的 MCP 客户端用同样的工具，令牌要另外勾「配置」，见 [MCP](mcp.md#改配置)；脚本可以直接调 [App API 的配置接口](../reference/app-api.md#配置)。

## 语音输入

接上 [Voltip](https://voltip.firlab.app/zh/) 的本机服务以后，网页对话页的输入框旁边多一个麦克风：点一下开始说，再点一下停下，pt-tools 把录音交给 Voltip 识别，文字填进输入框，看一眼再发。

1. 在 Voltip 里打开本机服务：桌面应用「设置 → 本机服务」打开「启用本机服务」，记下「接口地址」（默认 `http://127.0.0.1:47840/v1`），点「复制令牌」。没有桌面的服务器上用 `voltip-server`，`voltip-server --print-token` 打印令牌。详见 Voltip 文档的[本机服务](https://voltip.firlab.app/zh/recognition/service)。
2. 在 pt-tools 的「系统 → AI 助手设置」里找到「语音输入（Voltip）」，填 Voltip 的地址与访问令牌。
3. 点「测试语音输入」：pt-tools 读一次 Voltip 的处理方式列表，写明连没连上；「处理方式（模型）」的下拉框里是 Voltip 的预设与场景（`voltip` 是 Voltip 里设的默认处理方式，`voltip:raw` 不做 AI 润色）。
4. 「识别语言」选中文、英语或自动判断，保存。

- 浏览器只在 HTTPS 或 localhost 下给网页用麦克风。用 `http://<局域网地址>` 打开 pt-tools 时麦克风用不了，设置页与麦克风的提示里写明；放在 HTTPS 反向代理后面，或者在 pt-tools 所在的电脑上用 `http://localhost:<端口>` 打开。
- Voltip 的本机服务默认只接受同一台电脑的连接。pt-tools 在 Docker 里或者别的机器上时，`127.0.0.1` 指的是 pt-tools 自己：让 Voltip 监听别的地址要加 `--allow-remote`（`voltip-server --listen 0.0.0.0:47840 --allow-remote`），这时连接不加密，优先用 SSH 隧道或者 TLS 代理；Docker 里也可以用宿主机网络。
- 一段最长录 5 分钟，到了自动停下来识别；录音时按 Esc 取消。说完到出字要等 Voltip 识别（加上 AI 润色），一般几秒。
- 录音经 pt-tools 交给你填的 Voltip，不发给大模型服务商；Voltip 再按它自己的设置识别（内置服务、本地模型或你配的服务商）。访问令牌加密保存，只能改不能读；换了地址又没填新令牌时，保存会清掉存着的令牌。
- 目前只有网页对话页有语音输入，App 与通知渠道里没有。

## 在通知渠道里用

在「系统 → AI 助手设置」打开「通知渠道（ChatOps）」以后，绑定过的 Telegram、QQ 账号发的不是命令的消息（不以 `/` 开头）交给 AI 助手回答，命令照旧是命令。

- 每个绑定接着用同一个会话，上下文会带上前几轮；发 `/newchat` 开一个新会话（要等上一个回答结束）。
- 回答在后台生成，好了再发过来。一个绑定同时只回答一个问题：上一个还在回答时，新的消息会收到「还在回答」的提示。
- 要做改动类操作时，助手先发一条「需要你确认：…」。回复「确认」（或「确定」「是」「好的」「ok」「yes」）才执行；回复别的内容就取消这个操作。确认等待的时间过了也不执行，会再发一条超时提示。
- 只有管理员绑定能做改动类操作，其他绑定的助手拿不到这些工具。目前每个完成绑定的账号都是管理员，见 [ChatOps 快速开始](chatops-quickstart.md)。
- 发给助手的消息记在「操作审计」里，命令是 `assistant`（不记原文）；执行的操作另记一条，通道是「AI 助手」，触发用户是 `chatops:<绑定编号>`。
- 通知渠道里按纯文本发，太长的回答分几条发（最多 4 条，再长的省略）。

## 在 App 里用

手机 App 的「更多 → AI 助手」和网页上的对话页一样：打开最近的会话，回答一边生成一边显示，要做改动类操作时出现确认卡片。

- 配对时选了「完全控制」的设备才有「确认执行 / 拒绝」；只读的设备，助手拿不到改动类工具，只能查询。配对的设备读改不了 pt-tools 的配置；用 API 令牌的客户端，令牌勾了「配置」才能让助手看、改配置。
- App 里建的会话只在这台设备上看得到，网页上的会话也不出现在 App 里。
- 主机没有启用 AI 助手时，「更多」里不显示这一项。
- App 里还不能发附件、换模型与推理等级，用的是设置里的模型。
- 接口见 [App API](../reference/app-api.md#ai-助手)。

## 隐私与安全

- 对话内容、你发的附件、工具查到的结果（站点数据、种子标题、下载器状态、媒体库的目录）会发给所选的模型服务商。不想让数据出本机，就接自己部署的 Ollama。
- 打开了[用 AI 签到](site-login-monitoring.md#用-ai-识别验证码与答题)时，签到用的验证码图片和题目也会发给这个服务商。
- Cookie、Passkey、密码与种子下载链接不会交给模型：工具结果来自 App API，本来就不带这些；你贴的下载地址先换成站点与种子编号；存下来的对话与错误信息也遮掉了地址里的查询参数和长串。
- 工具返回的内容只当数据：种子标题、站内信里写的「指令」不会被照做。回答里的图片不显示，链接在新标签页打开，免去经图片地址把数据带出去的风险。
- AI 助手自己的设置（以及语音输入的设置）只能在网页上改（只认网页登录），助手也改不了。
- 对话进度经 SSE 推给页面。放在 Nginx 后面时 pt-tools 已经带了 `X-Accel-Buffering: no`；别的反向代理要关掉对这个地址的响应缓冲。

## 常见问题

**测试连接回 401 或 403**：API Key 不对或者没有这个模型的权限。

**测试连接回 404**：接口地址或模型名不对。OpenAI 的地址要带 `/v1`。

**测试连接回 429**：请求太快或者免费额度用完了。服务商要求等 20 秒以内时，pt-tools 等一等再试，最多两次；要等得更久就不再试，直接提示大概要等多久。到服务商控制台看额度，或者换个模型、服务商。

**测试连接回 400，说 User location is not supported**：这个服务商不对你所在的地区开放（Google AI Studio 不对中国大陆与香港开放）。在「代理」里填一个能访问它的代理。

**回 503，说 This model is currently experiencing high demand**：服务商的这个模型这会儿太忙（Google AI Studio 的新模型常见），过一会儿再试，或者换一个模型，例如 `gemini-flash-latest`。

**回 404，说模型对新用户不再开放**：服务商列表里还有这个模型，但新申请的 Key 用不了（例如 `gemini-2.5-flash`），换一个更新的模型。

**获取模型列表是空的，或者没有想要的模型**：列表按名字去掉了嵌入、语音、图像这类模型，留下的也不保证都支持工具调用，选好以后点「测试连接」看看。服务商没列出来的模型可以直接输入模型名。

**助手说「没有这个工具」**：模型自己编了一个工具名，换个说法再问，或者换一个工具调用更可靠的模型。

**回答说做不了改动类操作**：只有能写的入口才给模型改动类工具，网页上一直能用。

**提示「这个模型不认推理等级」**：服务商不支持这个模型的 `reasoning_effort`，或者不认这个值（例如有的模型没有「不思考」），这次按默认回答了。推理等级选「默认」就不再带。

**发了图片以后回 400**：多半是模型不能看图，换一个能看图的模型（例如各家带 vision、VL 的模型，Gemini、GPT 的新模型），或者去掉图片再发。

**对话里出现「前面几条消息已经压缩成摘要」**：上下文到了压缩阈值，见[上下文与压缩](#上下文与压缩)。压缩以后助手记得的是摘要，太早的细节可能不记得了，需要时再说一遍。

**改配置时说「没有要改的」**：给的值和现在一样，或者密钥交回了占位 `<已设置>`（表示不改）。

**改配置时说「不能改 xxx」**：这一类配置没有这个字段，或者这个字段只在新增时能填（比如 RSS 的站点、通知通道的类型）。回答里列着能改的字段。

**麦克风是灰的，提示要 HTTPS**：浏览器只在 HTTPS 或 localhost 下给网页用麦克风，见[语音输入](#语音输入)。

**语音识别说「连不上 Voltip」**：Voltip 的本机服务没开，或者 pt-tools 访问不到那个地址（Voltip 默认只接受同一台电脑的连接）。在设置页点「测试语音输入」看原因。

**语音识别说「Voltip 不认这个访问令牌」**：令牌在 Voltip 里重新生成过，重新复制一遍填进设置。

**语音识别说「Voltip 正忙」**：同时识别的请求满了，过几秒再点一次。
