# AI 助手

pt-tools 内置一个 AI 助手。接上一个大模型以后，可以在网页、手机 App 或者通知渠道（Telegram、QQ）里用自然语言问站点数据、下载器状态与抓到的种子，让它搜索种子、推送到下载器或者添加订阅。改动类操作每次都要你确认才执行。

助手在 pt-tools 后端运行，调用的是和 [MCP](mcp.md) 同一套工具，经 [App API](../reference/app-api.md) 执行：看到的数据、脱敏规则与 App 一样。任何 OpenAI 兼容的 Chat Completions 接口都能接，模型要支持工具调用（function calling）。

## 接上大模型

打开「系统 → AI 助手设置」：

1. 选服务商。选了预设会填好接口地址与常用模型；服务商下面写着有没有免费额度、要不要代理，「去申请 API Key」打开服务商申请 Key 的页面。
2. 填 API Key。
3. 选模型：点「获取模型列表」，pt-tools 用填好的地址与 Key 读服务商的模型列表，放进下拉框；也可以直接输入模型名。要选支持工具调用（function calling）的模型。
4. 点「测试连接」：pt-tools 发一条很短的消息，显示模型的回答与用时。
5. 打开「启用 AI 助手」，保存。

| 服务商                 | 接口地址                                                  | 模型                                                             |
| ---------------------- | --------------------------------------------------------- | ---------------------------------------------------------------- |
| DeepSeek               | `https://api.deepseek.com`                                | `deepseek-flash`、`deepseek-v4-pro`                              |
| 通义千问（阿里云百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1`       | `qwen3.7-plus`、`qwen3.8-flash`、`qwen3.8-max`                   |
| Kimi（月之暗面）       | `https://api.moonshot.cn/v1`                              | `kimi-k2.6`、`kimi-k3`                                           |
| 硅基流动               | `https://api.siliconflow.cn/v1`                           | 点「获取模型列表」选                                             |
| Google AI Studio       | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-flash-latest`、`gemini-3.8-flash`、`gemini-3.5-flash` 等 |
| Groq                   | `https://api.groq.com/openai/v1`                          | `qwen/qwen3.8-27b`、`openai/gpt-oss-120b`、`openai/gpt-oss-20b`  |
| OpenRouter             | `https://openrouter.ai/api/v1`                            | 点「获取模型列表」选                                             |
| Ollama（自己部署）     | `http://<Ollama 所在主机>:11434/v1`                       | `ollama list` 里的模型名，不要 API Key                           |
| OpenAI                 | `https://api.openai.com/v1`                               | `gpt-6.1-sol` 等                                                 |

表里的模型名是 2026 年 10 月各家文档上的，以服务商控制台为准。

- 接口地址填到 `/chat/completions` 之前，不带查询参数。
- API Key 加密保存，只能改、不能读出来。换了接口地址又没填新 Key 时，保存会清掉存着的 Key：Key 只发给保存它时的那个地址。
- 代理留空时用环境变量 `HTTP_PROXY`、`HTTPS_PROXY`；也可以单独填 `http://`、`https://` 或 `socks5://` 代理。获取模型列表、测试连接与对话都走这个代理。从中国大陆访问 Google AI Studio、Groq、OpenAI 一般要代理：Google AI Studio 对中国大陆与香港的地址回 `User location is not supported`。
- pt-tools 在 Docker 里、Ollama 在宿主机上时，地址要写宿主机的地址，不是 `127.0.0.1`。
- DeepSeek 等模型的思考模式会返回推理内容。pt-tools 把它存下来，只在后面的请求里回传给模型（带工具的请求要求回传），不在任何入口显示。

### 用免费额度

自己申请一个 Key，就能用这些服务商每天的免费额度。额度会调整，以服务商的页面为准：

| 服务商                 | 免费额度（2026 年 10 月）                                                  | 要知道的                                                        |
| ---------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Google AI Studio       | Gemini 的 Flash 等模型有免费额度，每分钟、每天限次数                       | 免费层的对话内容可能被 Google 用来改进产品；要代理              |
| Groq                   | 表里的三个模型免费，每个每天约 1000 次请求、20 万 token，每分钟 8000 token | 每分钟的 token 少，要调好几次工具的问题会多等一会儿；一般要代理 |
| 通义千问（阿里云百炼） | 新开通的账号每个模型各有一份免费额度，用完开始计费                         | 在百炼控制台给模型打开「免费额度用完即停」就不会多花钱          |
| 硅基流动               | 模型广场里标着「免费」的模型可以免费用，有限速                             | 选支持工具调用的模型                                            |
| OpenRouter             | 名字带 `:free` 的模型免费，每天有次数上限                                  | 选支持工具调用的模型                                            |

小模型调工具常常不可靠。回答总是不调工具、编工具名或者参数写错时，换一个大一点的模型。

设置里还有三个上限：

| 设置                     | 默认    | 说明                                                 |
| ------------------------ | ------- | ---------------------------------------------------- |
| 确认等待                 | 10 分钟 | 改动类操作等你确认的时间，1 到 60 分钟，过了就不执行 |
| 每次回答最多调用几轮工具 | 8       | 1 到 20；到了上限就停下来，提示换个说法再问          |
| 会话保留                 | 30 天   | 更新时间早于这么多天的会话每天清理一次；0 表示不清理 |

## 对话

打开「概览 → AI 助手」：左边是会话，右边是对话。可以这样问：

- 我的站点数据怎么样，哪个站分享率最低
- 下载器现在有多少在下载，剩余空间还有多少
- 最近 RSS 抓到了什么
- 搜一下 沙丘 2160p 的免费种子
- 把第二个推送到默认下载器
- 订阅《沙丘》第二季

回答一边生成一边显示。助手调用的工具折叠在回答下面，能看到参数与返回的数据。回答进行中可以点「停止」；同一个会话同时只回答一个问题，等它结束再问下一个。

你贴的种子下载地址会先换成「站点 X 的种子 Y」再交给模型，地址里的 passkey 不出 pt-tools；只认已配置站点的地址，磁力链接不收。

## 改动类操作要确认

暂停、继续、删除种子，推送种子到下载器，添加订阅，这几个操作执行以前，对话里会出现一张确认卡片，写明要做什么（例如「推送种子到下载器：站点 hdsky，种子编号 123，下载器 1」）。点「确认执行」才执行，点「拒绝」或者在确认等待时间里没有处理就不执行，助手会照实告诉你结果。

- 模型看不到也设不了确认的参数，确认只能由你点。
- 一次回答里要做几件事时逐个确认：前一个有了结论，才出现下一个。
- 同一个操作只算一次：两个页面同时点确认，或者确认与超时撞在一起，只有一个结论算数，操作最多执行一次。
- 停止回答、重启 pt-tools 时，还在等确认的操作都作废。
- 执行的操作记在「ChatOps → 操作审计」里：通道是「AI 助手」，命令是工具名，触发用户是会话的属主（网页上是 `web:<用户名>`）。经助手推送的种子在任务列表里的来源是 `assistant_push`。

## 在通知渠道里用

在「系统 → AI 助手设置」打开「通知渠道（ChatOps）」以后，绑定过的 Telegram、QQ 账号发的不是命令的消息（不以 `/` 开头）交给 AI 助手回答，命令照旧是命令。

- 每个绑定接着用同一个会话，上下文会带上前几轮；发 `/newchat` 开一个新会话（要等上一个回答结束）。
- 回答在后台生成，好了再发过来。一个绑定同时只回答一个问题：上一个还在回答时，新的消息会收到「还在回答」的提示。
- 要做改动类操作时，助手先发一条「需要你确认：…」。回复「确认」（或「确定」「是」「好的」「ok」「yes」）才执行；回复别的内容就取消这个操作。确认等待的时间过了也不执行，会再发一条超时提示。
- 只有管理员绑定能做改动类操作，其他绑定的助手拿不到这些工具。目前每个完成绑定的账号都是管理员，见 [ChatOps 快速开始](chatops-quickstart.md)。
- 发给助手的消息记在「操作审计」里，命令是 `assistant`（不记原文）；执行的操作另记一条，通道是「AI 助手」，触发用户是 `chatops:<绑定编号>`。
- 通知渠道里按纯文本发，太长的回答分几条发（最多 4 条，再长的省略）。

## 在 App 里用

手机 App 的「更多 → AI 助手」和网页上的对话页一样：打开最近的会话，回答一边生成一边显示，要做改动类操作时出现确认卡片。

- 配对时选了「完全控制」的设备才有「确认执行 / 拒绝」；只读的设备，助手拿不到改动类工具，只能查询。
- App 里建的会话只在这台设备上看得到，网页上的会话也不出现在 App 里。
- 主机没有启用 AI 助手时，「更多」里不显示这一项。
- 接口见 [App API](../reference/app-api.md#ai-助手)。

## 隐私与安全

- 对话内容、工具查到的结果（站点数据、种子标题、下载器状态）会发给所选的模型服务商。不想让数据出本机，就接自己部署的 Ollama。
- Cookie、Passkey、密码与种子下载链接不会交给模型：工具结果来自 App API，本来就不带这些；你贴的下载地址先换成站点与种子编号；存下来的对话与错误信息也遮掉了地址里的查询参数和长串。
- 工具返回的内容只当数据：种子标题、站内信里写的「指令」不会被照做。回答里的图片不显示，链接在新标签页打开，免去经图片地址把数据带出去的风险。
- 设置只能在网页上改（只认网页登录）。
- 对话进度经 SSE 推给页面。放在 Nginx 后面时 pt-tools 已经带了 `X-Accel-Buffering: no`；别的反向代理要关掉对这个地址的响应缓冲。

## 常见问题

**测试连接回 401 或 403**：API Key 不对或者没有这个模型的权限。

**测试连接回 404**：接口地址或模型名不对。OpenAI 的地址要带 `/v1`。

**测试连接回 429**：请求太快或者免费额度用完了。服务商要求等 20 秒以内时，pt-tools 等一等再试，最多两次；要等得更久就不再试，直接提示大概要等多久。到服务商控制台看额度，或者换个模型、服务商。

**测试连接回 400，说 User location is not supported**：这个服务商不对你所在的地区开放（Google AI Studio 不对中国大陆与香港开放）。在「代理」里填一个能访问它的代理。

**回 503，说 This model is currently experiencing high demand**：服务商的这个模型这会儿太忙（Google AI Studio 的新模型常见），过一会儿再试，或者换一个模型，例如 `gemini-flash-latest`。

**回 404，说模型对新用户不再开放**：服务商列表里还有这个模型，但新申请的 Key 用不了（例如 `gemini-2.5-flash`），换一个更新的模型。

**获取模型列表是空的，或者没有想要的模型**：列表按名字去掉了嵌入、语音、图像这类模型，留下的也不保证都支持工具调用，选好以后点「测试连接」看看。服务商没列出来的模型可以直接输入模型名。

**助手说「没有这个工具」**：模型自己编了一个工具名，换个说法再问，或者换一个工具调用更可靠的模型。

**回答说做不了改动类操作**：只有能写的入口才给模型改动类工具，网页上一直能用。
