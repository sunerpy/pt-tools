# 快速开始

本页按顺序完成首次配置：登录、添加下载器、添加站点认证、订阅 RSS，并确认第一次自动下载。尚未安装时，请先阅读[安装](install.md)。

## 1. 登录并修改密码

打开 `http://服务器地址:8080`，用初始账号登录（见[安装](install.md)中「首次登录」一节），然后在左侧导航「系统 → 修改密码」中更换密码。

## 2. 添加下载器

1. 打开「下载 → 下载器设置」，点击「添加下载器」。
2. 选择 qBittorrent 或 Transmission，填写 Web UI 地址、用户名和密码。
3. 保存后，下载器列表的「连通性」一列会显示检查结果；也可以点击该行的检查按钮重新检查。
4. 添加了多个下载器时，点击星标把常用的一个设为默认下载器。

下载器的目录、磁盘保护等选项见[配置说明](../configuration.md)。

## 3. 添加站点认证

打开「站点 → 站点列表」，点击要使用的站点，在「凭据」分页中填写认证信息。不同站点使用不同的认证方式：

- **Cookie**：大多数 NexusPHP 站点。推荐安装 [PT Tools Helper 浏览器扩展](browser-extension.md)，登录站点后一键同步 Cookie。
- **API Key**：例如 M-Team。
- **Passkey**：例如 Rousi Pro。

获取方法见[获取 Cookie 与 API Key](get-cookie-apikey.md)。保存后，站点列表的「状态」一列会显示能否正常访问。

## 4. 订阅 RSS

1. 在站点详情页打开「RSS 订阅」分页，点击添加。
2. 填写名称和 RSS 链接，选择下载器；可以选择下载路径、检查间隔和过滤规则。
3. 保存后，后台按检查间隔拉取订阅。

> [!WARNING]
> 没有关联任何过滤规则的订阅**只会下载免费种子**。追剧或下载非免费资源时，请先创建过滤规则，并按需关闭规则中的「仅免费」。

RSS 链接的获取方法和各选项的含义见 [RSS 订阅](rss-subscription.md)。

## 5. 按需添加过滤规则

打开「规则 → 过滤规则」，点击「添加规则」，填写关键词、通配符或正则，再回到 RSS 订阅中关联这条规则。写法和追剧示例见[过滤规则与追剧](filter-rules-tv-series.md)。只刷免费种子时不需要规则。

## 6. 确认第一次自动下载

- 「下载 → 任务列表」列出每一个被推送的种子，以及免费结束时间和推送状态。
- 「下载 → 下载器 Web UI」显示种子在下载器中的实际进度。
- 推送失败或没有符合条件的种子时，「系统 → 运行日志」会记录原因。

## 7. 备份密钥

把数据目录中的 `secret.key` 与数据库一起备份到另一台设备。丢失密钥后，已保存的 Cookie 无法解密。备份与恢复的方法见[升级与备份](upgrade.md)。
