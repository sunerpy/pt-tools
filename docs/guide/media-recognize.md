# 媒体识别

pt-tools 能解析种子标题，再到 TMDB 找对应的电影或剧集。[整理入库](media-library.md)按识别结果给文件命名，之后的订阅也会用到；在「媒体 → 媒体识别」里可以预览、纠正，并维护识别词。

电影与剧集的数据来自 [TMDB](https://www.themoviedb.org/)。本产品使用 TMDB API，但未经 TMDB 认可或认证。

## 填写 TMDB API Key

1. 在 TMDB 网站登录后，到账号设置的「API」页面申请（个人使用免费）。v3 的 API Key 与 v4 的 API 读取令牌都可以。
2. 在「TMDB 设置」里填写 API Key，选择语言，保存后点「测试连接」。

| 项目             | 说明                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| API Key          | 加密保存，界面只显示是否已设置；要更换时填写新的，点「清除」删除                           |
| 语言             | 简体中文（默认）、繁体中文、English、日本語；中文简介为空时用英文的                        |
| 代理地址（可选） | 访问 TMDB 用的代理，支持 http、https 与 socks5；留空时用环境变量里的代理（与访问站点相同） |

代理地址可以带用户名密码，整个地址加密保存，界面上密码显示为 `***`。中国大陆访问 TMDB 通常需要代理。

## 识别预览

在「识别预览」里填写标题（副标题与 IMDb 编号可选），点「识别」。

解析结果列出中英文名、年份、类型、季与集、分辨率、来源、编码、HDR、音轨、制作组，以及中字、国语、粤语等标记。副标题里的中文名、「第 1-10 集」「全 30 集」等也会读出来。

pt-tools 按下面的顺序找 TMDB 上的条目：

1. 手动纠正过的名字，直接用纠正的条目。
2. 有 IMDb 编号时，按编号查找。
3. 用中文名与英文名分别搜索，名字对得上、年份相符（剧集后面几季的年份晚于首播年份不算不符）才认定。名字只是部分相同时，续集编号要一致（Inside Out 不会认成 Inside Out 2），并且要明显好过第二个候选。只写了年份、没有季集标记的标题先按电影搜，没有可靠匹配时再搜剧集。种子名用英文名或罗马音（Your Name、Sousou no Frieren）、中文搜索结果里的名字对不上时，再比排在前面的几个候选在 TMDB 上的英文名与别名，名字完全相同、年份相符才认定。

没有认定时页面列出候选，可以点「选这个」，或填 TMDB 编号纠正。编号在 TMDB 网页地址里，比如 `themoviedb.org/movie/278` 里的 `278`。

搜索结果缓存一天，条目详情缓存一周。没填 API Key 时只做标题解析。

## 手动纠正

纠正按解析出的名字生效（电影另加年份，剧集不加）：同一个名字的其它标题，比如换了分辨率或制作组的，也会识别成纠正的条目。有英文名时按英文名记，中文名作为别名，所以同一个标题有没有中文副标题都能命中。在「手动纠正」里删除后，重新按名字搜索。

## 识别词

识别词在解析标题之前按顺序套用，用来处理站点或制作组的特殊写法。

| 种类     | 作用                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 屏蔽     | 从标题与副标题里去掉匹配的文字，比如 `[禁转]`                                                        |
| 替换     | 换成另一段文字，比如把简称 `TSR` 换成 `The.Shawshank.Redemption`                                     |
| 集数偏移 | 标题或副标题匹配时，集数加上偏移量（可为负）。用于按总集数编号的剧集：第二季从第 13 集开始时填 `-12` |

匹配纯文字时不分大小写；勾选「按正则匹配」时按 Go（RE2）的正则写法。

## IMDb 与豆瓣编号

pt-tools 会记下站点给出的 IMDb 与豆瓣编号：M-Team 的接口里的，以及 NexusPHP 站点详情页里的 IMDb 与豆瓣链接。RSS 下载与刷流推送时，编号写进种子记录：整理入库时优先按编号识别，之后的订阅也会用到。在识别预览里填了 IMDb 编号时，也优先按编号查找。

豆瓣编号之后用于「豆瓣想看」订阅；pt-tools 不调用豆瓣的接口。
