# 媒体识别 <Badge type="tip" text="1.0 预览版" />

pt-tools 能解析种子标题，再到 TMDB 找对应的电影或剧集。[整理入库](media-library.md)按识别结果给文件命名，之后的订阅也会用到；在「媒体 → 媒体识别」里可以预览、纠正，并维护识别词。

电影与剧集的数据与图片来自 [TMDB](https://www.themoviedb.org/)。pt-tools 使用 TMDB 与 TMDB API，但未经 TMDB 认可、认证或以其他方式批准（This application uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.）。

## TMDB API Key

发布的版本（Release 里的程序与 Docker 镜像）内置了 TMDB API Key，不用填写就能识别、整理与订阅，「TMDB 设置」的 API Key 下面写着「正在用内置的 Key」。也可以填自己的 Key，填了就用自己的：

1. 在 TMDB 网站登录后，到账号设置的「API」页面申请（个人使用免费）。v3 的 API Key 与 v4 的 API 读取令牌都可以。
2. 在「TMDB 设置」里填写 API Key，选择语言，保存后点「测试连接」。

这些情况要填自己的 Key：

- 自己从源码编译的版本没有内置的 Key。
- 换了 TMDB 接口地址（镜像或自建的中转）：内置的 Key 是大家共用的，只发给 TMDB 官方地址（`api.themoviedb.org` 与 `api.tmdb.org`），不发给别的地址。
- 内置的 Key 失效了，或者想用自己的 Key。

没有能用的 Key 时，探索、订阅与媒体库页上方会提示，并带一个到这里的链接。

| 项目                  | 说明                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------ |
| API Key               | 加密保存，界面只显示是否已设置；要更换时填写新的，点「清除」删除（有内置的 Key 时改用内置的）                      |
| 语言                  | 简体中文（默认）、繁体中文、English、日本語；中文简介为空时用英文的                                                |
| 代理地址（可选）      | 访问 TMDB 用的代理，支持 http、https 与 socks5；留空时用环境变量里的代理（与访问站点相同）                         |
| TMDB 接口地址（可选） | 换掉官方的 `https://api.themoviedb.org/3`，例如 `api.tmdb.org` 或自建的中转；只写域名时自动补上 `https://` 与 `/3` |
| TMDB 图片地址（可选） | 换掉官方的 `https://image.tmdb.org/t/p/`，例如图片镜像；只写域名时自动补上 `https://` 与 `/t/p/`                   |

代理地址可以带用户名密码，整个地址加密保存，界面上密码显示为 `***`。中国大陆访问 TMDB 通常需要代理；官方地址连不上或很慢时，也可以换接口地址与图片地址，两者可以和代理一起用。

刮削下载的图片、入库与订阅通知里的海报地址，以及网页和手机 App 上显示的海报，都用这里的图片地址。刮削和手机 App 的海报由 pt-tools 经上面的代理去取；网页上的海报由浏览器直接从图片地址加载，通知里的海报由收到通知的设备打开。图片地址换成内网的中转时，要确认浏览器和这些设备也能访问它；网页用 https 打开时，图片地址也要用 https，浏览器不会在 https 页面上加载 http 图片（设置页会提示）。

## 刮削的其它来源

整理入库刮削时除了 TMDB，还可以用这几个来源补充，在[媒体库的数据来源](media-library.md#数据来源)里按项选：

| 来源      | 补充什么                                                            | Key                           |
| --------- | ------------------------------------------------------------------- | ----------------------------- |
| 豆瓣      | 电影与每一季的中文简介、豆瓣评分                                    | 不用                          |
| Bangumi   | 动画的中文简介、评分与每一集的中文标题                              | 不用                          |
| Fanart.tv | 高清 Logo、Clearart、横幅、横版海报、碟片图，以及海报、背景与季海报 | 项目的 API Key；个人 Key 可选 |
| OMDb      | IMDb、烂番茄与 Metacritic 的评分，以及分级                          | API Key                       |

Fanart.tv 与 OMDb 的 Key 填在「刮削的其它来源」里，加密保存，界面只显示是否已设置；保存后点「测试」确认能用：

- Fanart.tv：在 fanart.tv 注册登录后，到「Get an API Key」页面申请项目（project）的 API Key，填进「项目的 API Key」。个人（personal）Key 可以不填；填了以后和项目的 Key 一起发，新上传的图片更快能用。
- OMDb：在 omdbapi.com 申请，免费的 Key 每天 1000 次；查过的条目缓存一段时间。

两个都经上面的代理访问。清除 Key 以后不再用这个来源：只有 Fanart.tv 有的图片不写，媒体库里选了它们的项用 TMDB 的。

## 识别预览

在「识别预览」里填写标题（副标题与 IMDb 编号可选），点「识别」。

解析结果列出中英文名、年份、类型、季与集、分辨率、来源、编码、HDR、音轨、制作组，以及中字、国语、粤语等标记。副标题里的中文名、「第 1-10 集」「全 30 集」等也会读出来。

pt-tools 按下面的顺序找 TMDB 上的条目：

1. 手动纠正过的名字，直接用纠正的条目。
2. 有 IMDb 编号时，按编号查找。
3. 用中文名与英文名分别搜索，名字对得上、年份相符（剧集后面几季的年份晚于首播年份不算不符）才认定。名字只是部分相同时，续集编号要一致（Inside Out 不会认成 Inside Out 2），并且要明显好过第二个候选。只写了年份、没有季集标记的标题先按电影搜，没有可靠匹配时再搜剧集。种子名用英文名或罗马音（Your Name、Sousou no Frieren、Dragon Raja）、中文搜索结果里的名字对不上时，再比排在前面的几个候选在 TMDB 上的英文名、别名与各语言的译名，名字完全相同、年份相符才认定。英文名带着副标题时（龙族的英文名是「Dragon Raja -The Blazing Dawn-」），种子名用的「Dragon Raja」常常只在法语、德语等的译名里。

没有认定时页面列出候选，可以点「选这个」，或填 TMDB 编号纠正。编号在 TMDB 网页地址里，比如 `themoviedb.org/movie/278` 里的 `278`。

搜索结果缓存一天，条目详情缓存一周。没有能用的 API Key 时只做标题解析。

## 手动纠正

纠正按解析出的名字生效（电影另加年份，剧集不加）：同一个名字的其它标题，比如换了分辨率或制作组的，也会识别成纠正的条目。有英文名时按英文名记，中文名作为别名，所以同一个标题有没有中文副标题都能命中。在「手动纠正」里删除后，重新按名字搜索。

## 识别词

识别词在解析标题之前按顺序套用，用来处理站点或制作组的特殊写法。

| 种类     | 作用                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 屏蔽     | 从标题与副标题里去掉匹配的文字，比如 `[禁转]`                                                        |
| 替换     | 换成另一段文字，比如把简称 `TSR` 换成 `The.Shawshank.Redemption`                                     |
| 集数偏移 | 标题或副标题匹配时，集数加上偏移量（可为负）。用于按总集数编号的剧集：第二季从第 13 集开始时填 `-12` |

匹配纯文字时不分大小写；勾选「按正则匹配」时按 Go（RE2）的正则写法。

## IMDb 与豆瓣编号

pt-tools 会记下站点给出的 IMDb 与豆瓣编号：M-Team 的接口里的，以及 NexusPHP 站点详情页里的 IMDb 与豆瓣链接。RSS 下载与刷流推送时，编号写进种子记录：整理入库时优先按编号识别，之后的订阅也会用到。在识别预览里填了 IMDb 编号时，也优先按编号查找。

豆瓣编号用于「豆瓣想看」订阅；媒体库的「简介与评分」选了豆瓣时，刮削也按它取豆瓣的简介与评分（见[刮削](media-library.md#刮削)）。
