# RSS 订阅配置指南

本页介绍如何获取站点的 RSS 链接、在 pt-tools 中添加订阅，以及各个选项的作用。

## 什么是 RSS 订阅

> [!WARNING]
> **默认只下载免费种子**：订阅没有关联过滤规则、下载模式为默认的「智能」时，RSS 订阅**只会自动下载免费种子**，不会下载非免费种子。如果您只是刷流，无需设置任何过滤规则，直接添加 RSS 订阅即可。只有在需要追剧或下载特定资源（即便种子非免费也要下载）时，才需要前往「过滤规则」页面创建规则，并关闭规则中的「仅免费」开关。详见 [过滤规则与追剧指南](filter-rules-tv-series.md)。

RSS (Really Simple Syndication) 是一种网络内容聚合格式。在 PT (Private Tracker) 站点中，RSS 用于发布最新的种子信息。

通过配置 RSS 订阅，pt-tools 可以：

1. 定期检查站点发布的最新种子
2. 按下载模式和过滤规则（标题关键词、体积、是否免费等）决定是否下载
3. 将符合条件的种子推送到下载器（qBittorrent、Transmission）

这是实现"全自动刷流"和"自动追剧"的核心功能。

## 获取 RSS 链接

不同的 PT 站点架构，获取 RSS 链接的方式略有不同。

### NexusPHP 架构站点 (如 HDSky, HDDolby)

这类站点通常基于 Cookie 进行认证，RSS 链接中可能会包含用户的 `passkey`，请勿泄露自己的 RSS 链接。

**步骤：**

1. 登录站点，进入**种子页面 (Torrents)** 或 **首页**。
2. 寻找 RSS 图标或「订阅」链接，通常在页面右上角、消息通知图标附近。
3. 选择要订阅的分类（如剧集）、清晰度等条件和每页条数，然后生成 RSS 链接。
4. 复制生成的链接（一般选择面向支持 RSS 的 BT 客户端的那个地址）。
5. 链接格式通常如下：
   `https://site.com/torrentrss.php?rows=10&linktype=dl&passkey=YOUR_PASSKEY`

**参数说明：**

- `rows`: 返回的种子数量 (建议设置为 10-50)
- `linktype`: 链接类型，通常必须包含 `dl` 以直接获取下载链接
- `passkey`: 你的个人密钥，**请勿泄露**

### mTorrent 架构站点 (如 M-Team)

这类较新的站点通常使用 API Key 或特殊的 RSS 生成页面。

**步骤（以 M-Team 为例）：**

1. 登录站点，进入 **用户中心** 或 **个人设置**。
2. 找到 **API / RSS** 设置部分。
3. 生成一个新的 API Key (如果需要)。
4. 在 RSS 生成器中选择你需要的分类（如 Movie, TV）。
5. 复制生成的链接。
6. 链接格式示例：
   `https://rss.m-team.cc/api/rss/fetch?dl=1&pageSize=10&sign=XXXX&t=XXX&tkeys=ttitle&uid=XXX`

## 在 pt-tools 中添加订阅

1. 打开 站点 → 站点列表，点击站点所在行的「站点配置与 RSS 订阅」按钮，进入站点页面。
2. 切换到「RSS 订阅」标签，点击「添加 RSS」。
3. 填写名称和链接，按需设置下面的选项，然后保存。

保存后，订阅按检查间隔在后台运行。推送的种子显示在 下载 → 任务列表 中；没有推送时，系统 → 运行日志 会记录原因。

## 订阅选项

| 选项             | 说明                                                                   | 默认值     |
| ---------------- | ---------------------------------------------------------------------- | ---------- |
| **名称**         | 订阅的名称，方便识别                                                   | 必填       |
| **检查间隔**     | 多久拉取一次，单位分钟，可设 5–1440                                    | `10`       |
| **链接**         | 站点的 RSS 地址                                                        | 必填       |
| **分类**         | 推送到下载器时使用的分类                                               | 空         |
| **标签**         | 推送到下载器时添加的标签                                               | 空         |
| **下载器**       | 推送到哪个下载器；未启用的下载器不能选                                 | 默认下载器 |
| **下载路径**     | 下载器中预设的目录，或切换到「自定义」手动填写；留空使用下载器默认路径 | 空         |
| **过滤规则**     | 关联的过滤规则，可多选                                                 | 不关联     |
| **下载模式**     | 跟随全局、智能、仅过滤规则或仅免费，见下文                             | 跟随全局   |
| **免费结束暂停** | 免费期结束时如果尚未下载完成，自动暂停任务                             | 关闭       |
| **通知模式**     | 有新种时是否推送通知，见 [RSS 上新通知](chatops-rss-notify.md)         | 不通知     |

### 下载模式

| 模式             | 行为                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| **智能**（推荐） | 没有关联过滤规则时只下载免费种子；关联了规则后只下载匹配规则的种子，不再自动下载未匹配的免费种子 |
| **仅过滤规则**   | 只下载匹配过滤规则的种子；没有关联规则的订阅不会下载任何种子                                     |
| **仅免费**       | 只下载免费种子，忽略过滤规则，适合纯刷流                                                         |
| **跟随全局**     | 使用 系统 → 全局设置 中的「默认下载模式」，默认是智能                                            |

免费种子还要能在免费期内下载完成才会推送，判断方法见 [配置说明](../configuration.md) 中的限速与最短免费时间。全局设置中的种子大小上限和下限对所有模式都生效。

### 过滤规则

过滤规则在 规则 → 过滤规则 中创建，再关联到订阅：

- **匹配方式**：关键词、通配符或正则，可以只匹配标题、只匹配标签，或者两者都匹配。
- **体积范围**：最小和最大体积（GB），不能突破全局上限。
- **仅免费**：开启后，这条规则只放行免费种子。
- **用途**：控制下载、控制上新通知，或者两者都控制。

语法和追剧示例见 [过滤规则与追剧指南](filter-rules-tv-series.md)。

## 最佳实践

1. **合理设置间隔**：不要设置过短的间隔（如小于 5 分钟），以免对站点服务器造成压力导致封号。建议 `10` 到 `30` 分钟。
2. **先测试后自动**：关联规则前，先在过滤规则页面用「测试匹配」拿一个订阅的实时数据试一下；开启后观察运行日志，确认结果符合预期。
3. **利用站点自身的过滤**：如果站点 RSS 生成器支持选择分类（如只选电影），优先在生成链接时过滤，减少本地处理压力。
4. **分类管理**：为 RSS 下载的任务设置独立的下载器分类，方便后续自动化媒体库管理（如 Jellyfin）。
5. **保护 Passkey**：在分享配置或截图时，务必打码 RSS 链接中的 `passkey` 或 `apikey` 参数。

## 常见问题排查

### 1. RSS 获取失败 (HTTP 403/401)

- **原因**：认证失效或 Passkey 错误。
- **解决**：检查链接中的 passkey 是否正确；如果是需要 Cookie 的站点，确认 pt-tools 中是否配置了有效的站点 Cookie。

### 2. 获取成功但无种子

- **原因**：RSS 链接本身没有返回内容，或者所有内容都被下载模式和过滤规则拦截了。
- **解决**：
  - 在浏览器中直接打开 RSS 链接，看是否有 XML 内容返回。
  - 检查 `rows` 参数是否太小。
  - 检查下载模式：智能模式下关联了规则，就只下载匹配规则的种子。
  - 在运行日志中查看每个种子被跳过的原因。

### 3. 下载器无法添加任务

- **原因**：下载器连接失败、路径不存在或权限不足。
- **解决**：检查下载器配置连通性；确认下载路径在下载器所在的机器上真实存在且可写。

### 4. 无法识别促销状态

- **原因**：部分站点的 RSS 不直接包含促销信息，或者工具未适配该站点的特殊字段。
- **解决**：尝试更新 pt-tools 到最新版本；或者依赖站点详情页抓取（如果支持）。
