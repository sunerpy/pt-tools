# 刷流任务

刷流任务从一个站点的免费种子列表里，按你定的条件挑新种推送给下载器，做种一段时间后按规则删掉，把上传量和魔力攒起来。它和 RSS 订阅是两条独立的流程，开启刷流不会改变 RSS 的行为。

刷流会增加对站点的请求，也会让下载器持续进出种子。开启前请确认站点规则允许刷流，并留意站点对新种下载速度、H&R 和做种时长的要求。

## 新建任务

在左侧导航「下载 → 刷流任务」里点「新建任务」。一个任务对应一个站点和一个下载器：

| 设置       | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 站点       | 只能选内置站点，站点要先在「站点列表」里配置好凭证并启用                     |
| 下载器     | 种子推给哪个下载器；保存路径、分类留空时用下载器的默认值                     |
| 额外标签   | 可选。站点名、`pt-tools-brush` 和任务专属标签 `pt-brush-<任务编号>` 总会带上 |
| 检查间隔   | 每隔多久运行一轮，最短 5 分钟，默认 10 分钟                                  |
| 保存后开启 | 新任务默认关闭，确认配置无误后再开启                                         |

任务开启后，每一轮依次做三件事：给任务名下的种子采样（记录上传、下载量）、按删种规则删除、在限额之内加新种。

## 入场条件

每一轮只请求一次站点的种子列表（走站点自己的限速），再在本地逐条判断：

- **优惠类型**：默认只收「免费」和「2x 免费」，也可以加上 50%、2x 50% 等。部分站点（如 M-Team）的列表会混入普通种，同样在这里拦下。
- **优惠剩余**：优惠还剩多久才收，默认至少 60 分钟；没有到期时间的永久免费不受限制。
- **体积**：最小、最大体积（GB），0 表示不限。设了体积限制、但列表里看不出体积的种子不收。
- **做种人数不多于**、**下载人数不少于**：用来挑人多、竞争小的种子。
- **发布不超过**：只收发布不久的新种，0 表示不限。
- **标题包含 / 排除**：每行或逗号分隔，大小写不敏感，同时匹配标题和副标题。
- **排除 H&R**：默认开启。站点开启了整站 H&R 时，整站的种子都按 H&R 处理（与 RSS 下载同一规则）。关掉之后也只收站点定义里算得出做种要求的 H&R 种子：要求时长未知时，删种规则没法判断什么时候可以删。

符合条件的种子按下载人数从多到少、做种人数从少到多排序，依次加入。任何刷流任务在这个站点推送过的种子（包括已经删掉的）不会再加回来，同一个种子也不会被两个任务各加一份；下载器里已经有的种子同样跳过。

## 限额

| 限额       | 说明                                           |
| ---------- | ---------------------------------------------- |
| 同时下载数 | 任务名下还在下载的种子数上限，1–50，必填       |
| 任务总体积 | 任务名下所有在做种子的体积合计上限，0 表示不限 |
| 每天加入   | 当天加入的种子体积合计上限，0 表示不限         |

推送和 RSS 下载走同一个入口，磁盘保护与站点做种容量的检查照常生效。某个种子被这两道检查拒绝时，这一轮停止加种，下一轮再试；连续 3 个种子文件下载失败、或者种子加进下载器之后本地记录写不进去（这个种子会被撤回）时，也停止这一轮。

## 删种规则

下面的规则任一条满足就删，删除时默认连数据一起删（可以改成只从下载器移除）；数据还被别的种子用着时（比如给它加了[辅种](reseed.md)），只删种子、保留数据：

- **做种满 N 小时**：只对已经下完的种子算。
- **分享率达到 N**。
- **平均上传低于 N KB/s**：按最近 M 分钟（默认 30）的上传量算，只对已经下完、做种满 M 分钟、采样也覆盖了这段时间的种子判断。
- **没有活动 N 小时**：这段时间里上传量和下载量都没有增长。
- **免费即将到期、尚未下完**：默认开启。下一轮检查之前就会到期的，这一轮就删，避免到期之后的下载按非免费计。

有 H&R 的种子在做种时长达到站点要求之前一律不删，包括免费到期时尚未下完的情况。

下载完成按「进度 100% 并且不在校验、出错状态」判断；校验中或文件丢失的种子不算下完。

刷流只处理带本任务标签、并且是本任务加入的种子。你把某个种子的任务标签去掉，它就交还给你，刷流不再删它；手动删掉或被其他方式删掉的种子，记录会标成「已不在下载器」。任务换了下载器之后，已经加入的种子仍在原来的下载器里采样、按规则删除；原来的下载器暂时连不上时，那些种子这一轮不动。

## 与自动清理的关系

刷流种子都带 `pt-tools-brush` 标签。「自动清理」的常规规则（做种时长、分享率等）跳过这些种子，由刷流任务自己的删种规则处理，两套规则不会争抢。磁盘空间低于保底线时的紧急清理仍然覆盖所有种子，包括刷流种子。

## 关闭与删除任务

- **关闭**：不再加新种。已加入的种子继续按删种规则处理，直到全部删完。
- **删除**：任务与它的统计、种子记录一起删除，下载器里的种子保留，之后不再由刷流管理（自动清理的常规规则也仍然跳过它们，需要时手动处理）。
- 任务正在运行一轮时不能删除或修改，稍后再试（一轮用的是开始时读到的配置）。

## 收益与战报

刷流任务页顶部是在做种子数、今日上传和下载、累计分享率；「30 天收益」卡按天画出全部任务的上传量。收益的口径是刷流种子在下载器里的累计上传、下载量相邻两次采样之差，按服务器时区分天；两次采样跨过午夜时，这段增量按时长分摊到两天。

开启了[每日战报](user-stats.md#每日战报)时，当天有刷流收益的话，战报里会多一节「今日刷流」：合计的上传、下载、加入和删除数，任务多于一个时逐个列出。

## 从 Vertex 迁移

pt-tools 的刷流参考了 Vertex 的常用玩法，概念大致对应如下：

| Vertex                         | pt-tools                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| 刷流任务（RSS 任务）           | 刷流任务：一个任务对应一个站点和一个下载器，选种来自站点的免费种子列表而不是 RSS 链接   |
| 选种规则                       | 入场条件：优惠类型、优惠剩余、体积、做种 / 下载人数、发布时长、标题包含与排除、排除 H&R |
| 删种规则                       | 删种规则：做种时长、分享率、平均上传速度、无活动时长、免费到期未完成，任一条满足即删    |
| 下载器限制（最大下载数、空间） | 限额：同时下载数、任务总体积、每天加入；磁盘保护与站点做种容量沿用全局设置              |
| 标签 / 分类                    | 额外标签与分类；`pt-tools-brush` 与任务标签自动带上                                     |

pt-tools 目前不支持 Vertex 的自定义脚本规则；需要更复杂的条件时，可以拆成几个条件不同的任务。

## 接口

| 接口                                                               | 说明                                                           |
| ------------------------------------------------------------------ | -------------------------------------------------------------- |
| `GET` / `POST /api/brush/tasks`                                    | 列出任务（含在做种子数与收益）/ 新建任务                       |
| `GET` / `PUT` / `DELETE /api/brush/tasks/<编号>`                   | 读取、修改、删除任务                                           |
| `POST /api/brush/tasks/<编号>/run`                                 | 立即运行一轮，返回这一轮的结果；站点或下载器出错没跑完时回 502 |
| `GET /api/brush/tasks/<编号>/torrents?state=active\|removed\|gone` | 任务名下的种子                                                 |
| `GET /api/brush/stats?days=<1–90>`                                 | 最近若干天各任务与合计的每日收益                               |

这些接口都要求登录。
