# 过滤规则与追剧指南

本文档详细介绍了如何使用 pt-tools 的过滤规则功能，实现自动追剧、下载特定资源等高级用法。

## 过滤规则概述

> [!WARNING]
> **大多数用户无需设置过滤规则**：在未关联任何过滤规则的情况下，RSS 订阅**默认只会下载免费种子**。如果您只是刷流，无需创建任何过滤规则，直接添加 RSS 订阅即可。过滤规则仅适用于以下场景：需要追剧或下载特定资源，并且即便种子非免费也希望自动下载。此时需要创建过滤规则，关闭规则中的「仅免费」开关，并把规则关联到对应的 RSS 订阅。

过滤规则是 pt-tools 的核心功能之一，它可以对 RSS 订阅中的种子进行精细化筛选，实现：

- **自动追剧**：只下载特定剧集的最新集数
- **质量筛选**：只下载 4K、1080p 等特定分辨率
- **来源筛选**：只下载特定字幕组或发布组的资源
- **免费优先**：默认只下载免费种子，节省下载量

**特色功能**：可配置下载符合过滤条件的**非免费种子**，适用于追更特定资源时不错过任何更新。

> [!NOTE]
> 订阅的下载模式为默认的「智能」时，一旦关联了过滤规则，就**只下载匹配规则的种子**，未匹配的免费种子不再自动下载。既想追剧又想继续刷免费种，可以为追剧单独添加一个订阅。下载模式的说明见 [RSS 订阅配置指南](rss-subscription.md)。

## 匹配模式详解

pt-tools 支持三种匹配模式，从简单到复杂。三种模式都不区分大小写，只要标题（或标签）中**有一段**符合即算匹配，不要求从头到尾完全一致。

| 模式           | 难度 | 适用场景     | 示例                 |
| -------------- | ---- | ------------ | -------------------- |
| **关键词**     | 简单 | 包含特定词汇 | `REMUX`、`黑镜`      |
| **通配符**     | 中等 | 简单模式匹配 | `*.2024.*`, `S01E??` |
| **正则表达式** | 复杂 | 精确复杂匹配 | `S\d{2}E\d{2}`       |

### 关键词匹配

最简单的匹配方式，标题或标签中包含指定关键词即匹配成功。

**匹配规则**：

- 不区分大小写
- 整段文字作为**一个**关键词：`4K,2160p` 只匹配标题里连续出现的 `4K,2160p`，不会拆成两个关键词
- 需要「任一关键词匹配即成功」时，请改用正则表达式，用 `|` 分隔，如 `4K|2160p|UHD`

**示例**：

```
REMUX
```

匹配结果：标题中包含 `REMUX`（或 `remux`）的种子都会被匹配。

### 通配符匹配

使用 `*` 和 `?` 进行模式匹配，比关键词更灵活。

**语法**：

- `*` 匹配任意数量的任意字符
- `?` 匹配单个任意字符

**示例**：

| 模式                 | 说明           | 匹配示例                 |
| -------------------- | -------------- | ------------------------ |
| `*.2024.*`           | 包含 2024 年份 | `Movie.2024.1080p`       |
| `S01E??`             | 第一季任意集   | `S01E01`, `S01E12`       |
| `*REMUX*`            | 包含 REMUX     | `Movie.REMUX.2160p`      |
| `Show.Name.S??E??.*` | 任意季任意集   | `Show.Name.S02E05.1080p` |

### 正则表达式匹配

最强大的匹配方式，支持复杂的模式定义。

**常用语法**：

| 语法     | 说明               | 示例                    |
| -------- | ------------------ | ----------------------- |
| `\d`     | 匹配数字           | `\d` 匹配 `0-9`         |
| `\d{2}`  | 匹配两位数字       | `\d{2}` 匹配 `01`, `99` |
| `\d+`    | 匹配一个或多个数字 | `\d+` 匹配 `1`, `123`   |
| `.*`     | 匹配任意内容       | `A.*B` 匹配 `A123B`     |
| `(A\|B)` | 匹配 A 或 B        | `(4K\|2160p)`           |
| `^`      | 匹配开头           | `^Movie`                |
| `$`      | 匹配结尾           | `1080p$`                |

**常用模式**：

| 用途     | 正则表达式          | 匹配示例             |
| -------- | ------------------- | -------------------- |
| 剧集编号 | `S\d{2}E\d{2}`      | `S01E01`, `S02E15`   |
| 4K 资源  | `(4K\|2160p\|UHD)`  | `4K`, `2160p`        |
| 特定季   | `S01E\d{2}`         | `S01E01` 到 `S01E99` |
| 年份     | `\.(19\|20)\d{2}\.` | `.2024.`, `.1999.`   |

## 过滤规则配置

在 规则 → 过滤规则 中点击「添加规则」，填写以下字段：

| 字段                   | 说明                                                       | 默认值     |
| ---------------------- | ---------------------------------------------------------- | ---------- |
| **名称**               | 规则的标识名称，如「追剧-某剧名」                          | 必填       |
| **优先级**             | 数字越小越先匹配                                           | `100`      |
| **模式类型**           | 关键词 / 通配符 / 正则表达式                               | 关键词     |
| **匹配范围**           | 仅标题 / 仅标签 / 标题和标签                               | 标题和标签 |
| **匹配模式**           | 要匹配的内容，按模式类型填写；「常用模板」可以一键填入示例 | 必填       |
| **最小大小、最大大小** | 体积范围（GB），0 表示不限；最大值不能突破全局上限         | `0`        |
| **规则用途**           | 下载、通知，或两者都控制                                   | 下载       |
| **仅免费**             | 开启后这条规则只放行免费种子                               | 开启       |
| **启用规则**           | 关闭后规则保留，但不参与匹配                               | 开启       |

**仅免费说明**：

- **开启**：只下载免费种子，适合日常刷流
- **关闭**：即使非免费也下载，适合追更不想错过的内容

规则创建后，还要在站点页面的「RSS 订阅」中编辑订阅，在「过滤规则」里选中它，才会生效。

## 追剧实战案例

### 案例 1：追更特定剧集

**场景**：追更某部美剧第一季，不想错过任何更新。

**配置**：

```
名称: 追剧-某美剧S01
模式类型: 正则表达式
匹配模式: 某美剧名称.*S01E\d{2}
匹配范围: 仅标题
仅免费: 关闭
```

**说明**：

- `某美剧名称.*S01E\d{2}` 会匹配如 `某美剧名称.S01E01.1080p.WEB-DL`
- 关闭「仅免费」，确保即使非免费也能下载

### 案例 2：只下载 4K 资源

**场景**：只下载 4K/2160p 分辨率的电影资源。

**配置**：

```
名称: 4K电影
模式类型: 正则表达式
匹配模式: 4K|2160p|UHD
匹配范围: 仅标题
仅免费: 开启
```

**说明**：

- 多个候选词用 `|` 分隔，任一出现即匹配；这也是「常用模板」里「4K 资源」的写法
- 关键词模式不会按逗号拆分，`4K,2160p,UHD` 写成关键词会匹配不到

### 案例 3：指定字幕组/发布组

**场景**：只下载特定字幕组的资源。

**配置**：

```
名称: 指定字幕组
模式类型: 通配符
匹配模式: *SubGroup*
匹配范围: 仅标题
仅免费: 开启
```

**或使用正则表达式**：

```
名称: 指定字幕组
模式类型: 正则表达式
匹配模式: (SubGroup1|SubGroup2|SubGroup3)
匹配范围: 仅标题
仅免费: 开启
```

### 案例 4：排除特定内容

**场景**：排除 HDSWEB 标签的种子。

**方法**：pt-tools 的过滤规则是「包含匹配」，如需排除特定内容，可以：

1. **利用站点 RSS 过滤**：在生成 RSS 链接时，选择不包含特定分类
2. **使用精确匹配**：只匹配需要的内容，而不是排除不需要的

**示例**：如果只想要 WEB-DL 而不要 HDTV：

```
名称: 只要WEB-DL
模式类型: 正则表达式
匹配模式: WEB-DL|WEBDL|WEBRip
匹配范围: 仅标题
仅免费: 开启
```

### 案例 5：综合条件筛选

**场景**：追更某剧的 4K 版本，由特定字幕组发布。

**配置**：

```
名称: 某剧-4K-字幕组
模式类型: 正则表达式
匹配模式: 某剧名.*S01E\d{2}.*(2160p|4K).*SubGroup
匹配范围: 仅标题
仅免费: 关闭
```

**说明**：

- 正则表达式可以组合多个条件
- `.*` 用于匹配中间的任意内容

## 工作流程

```
RSS 订阅获取新种子
        |
        v
+--------------------------+
| 按优先级从小到大检查      |
| 订阅关联的过滤规则        |
+--------------------------+
        |
        v
  有规则匹配上吗？
    /        \
   有         没有
   |           |
   v           v
+----------------------+  +--------------------+
| 只看第一条匹配的规则  |  | 按订阅的下载模式处理 |
| - 仅免费 且 非免费？  |  | （智能模式关联了规则 |
| - 体积超出规则范围？  |  |   时直接跳过）       |
+----------------------+  +--------------------+
   |
 任一为是 → 跳过该种子
 都为否   → 推送到下载器
```

全局设置中的种子大小上限和下限在规则之前检查，超出时直接跳过。

## 正则表达式速查

### 剧集匹配

| 需求             | 正则表达式              |
| ---------------- | ----------------------- |
| 任意剧集         | `S\d{2}E\d{2}`          |
| 第一季           | `S01E\d{2}`             |
| 第一季第1-9集    | `S01E0[1-9]`            |
| 第一季第10集以后 | `S01E(1[0-9]\|[2-9]\d)` |
| 季度合集         | `S\d{2}\.Complete`      |

### 质量匹配

| 需求       | 正则表达式                   |
| ---------- | ---------------------------- |
| 4K 资源    | `(4K\|2160p\|UHD)`           |
| 1080p 资源 | `1080p`                      |
| 高清资源   | `(1080p\|2160p\|4K)`         |
| REMUX      | `REMUX`                      |
| Blu-ray    | `(BluRay\|Blu-ray\|BDREMUX)` |

### 来源匹配

| 需求     | 正则表达式                |
| -------- | ------------------------- |
| WEB 资源 | `(WEB-DL\|WEBDL\|WEBRip)` |
| HDTV     | `HDTV`                    |
| 非 HDTV  | `WEB` (只匹配 WEB 类型)   |

## 最佳实践

### 1. 规则命名规范

使用清晰的命名方便管理：

- `追剧-剧名-季数`
- `4K-电影`
- `字幕组-组名`

### 2. 合理设置优先级

优先级数字越小越先检查，而且只有第一条匹配上的规则会决定结果：

- 数字小：追更特定内容（如正在追的剧）
- 数字居中：质量筛选规则
- 数字大：通用规则

### 3. 渐进式配置

1. 先用简单的关键词规则测试
2. 确认匹配正确后再细化
3. 使用正则表达式进行精确控制

### 4. 定期维护

- 已完结的剧集：将规则设为禁用或删除
- 新季开播：更新规则中的季数
- 检查规则效果：确认没有误匹配

### 5. 配合 RSS 站点过滤

先在站点 RSS 设置中进行粗筛：

- 选择特定分类（电影、电视剧、动漫）
- 限制返回数量

然后用 pt-tools 过滤规则进行精筛。

## 常见问题

### Q: 为什么规则不生效？

A: 检查以下几点：

1. 规则是否已启用，并且已关联到 RSS 订阅
2. 匹配模式是否正确（注意转义字符；关键词模式不会按逗号拆分）
3. 匹配范围是否选对（标题/标签）
4. 种子标题是否真的符合规则
5. 是否有优先级更小的规则先匹配上了，但因「仅免费」或体积范围把种子挡掉了

### Q: 正则表达式如何调试？

A: 建议：

1. 添加或编辑规则时，在「试跑」里选择一个 RSS 订阅，点击「测试匹配」，查看返回结果是否符合预期
2. 先用简单模式，逐步增加复杂度
3. 查看 pt-tools 运行日志，确认匹配情况

### Q: 多个规则如何协同工作？

A: 一个订阅关联多条规则时：

- 按优先级从小到大检查，种子匹配任一规则即可能被下载
- 第一条匹配上的规则决定结果，不再检查后续规则
- 这条规则要求免费而种子非免费，或者体积不在它的范围内，种子就会被跳过

### Q: 如何避免重复下载？

A: pt-tools 会自动记录已下载的种子：

- 相同种子不会重复下载
- 基于站点和种子 ID 判断
- 历史记录保存在数据库中

### Q: 非免费下载会消耗多少流量？

A: 这取决于站点政策和种子大小：

- 请确保你有足够的下载额度
- 建议设置最大种子大小限制
- 追剧场景下，单集通常 2-10GB
