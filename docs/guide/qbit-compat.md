# qB 兼容入口 <Badge type="tip" text="1.0 预览版" />

qB 兼容入口让 MoviePilot、IYUU、autobrr、Sonarr、Radarr 这类只认 qBittorrent 的工具把 pt-tools 当成一台 qBittorrent。它们加的种子经 pt-tools 推到你选的真实下载器，照常经过磁盘空间保护与站点做种容量的检查；种子记录、站点标签与操作审计也都留在 pt-tools 里。

兼容入口在单独的端口上，默认不开。

## 开启

1. 在「下载 → qB 兼容入口」打开「监听」，填监听地址（写成「地址:端口」，例如 `0.0.0.0:8081`；`0.0.0.0` 是所有网卡，`127.0.0.1` 只给本机），保存后马上生效。端口被占了、地址写错时，页面写明监听失败的原因。Docker 部署时还要把这个端口映射出来：

   ```yaml
   ports:
     - "8081:8081"
   ```

   也可以在启动时加参数 `--qbit-compat-addr 0.0.0.0:8081`，或者设环境变量 `PT_QBIT_COMPAT_ADDR`：它们优先于页面上设的地址，给了时页面上的地址只读，改了要重启。

2. 在同一页选背后的下载器（不选时用默认下载器；停用的下载器列出来但选不了，选的下载器停用或删掉以后页面写明原因），需要时打开「完全控制」（打开前要确认）。
3. 新建一个有「qB 兼容」权限的 API 令牌：页面上「新建一个」的链接会打开「系统 → API 令牌」的新建，权限已经选好，见 [API 令牌](api-tokens.md)。

页面的「状态」写明是否在监听、地址从哪来（启动参数、环境变量或这页设的）、登录着的客户端数，以及最近一次成功与失败的登录（时间、地址、用的令牌、失败原因）；这些登录记录在 pt-tools 重启以后重新算。

## 客户端怎么填

在工具的下载器设置里新增一台 qBittorrent：

| 项目   | 填什么                                      |
| ------ | ------------------------------------------- |
| 地址   | `http://<pt-tools 所在主机>:8081`           |
| 用户名 | 随意，例如 `pt-tools`（会记进操作审计）     |
| 密码   | 有「qB 兼容」权限的 API 令牌（`ptt_` 开头） |

- Sonarr、Radarr 这类按分类收种子的工具会先建分类再加种子，兼容入口都接受；建分类时给的目录会用作这个分类的保存目录。
- IYUU 辅种给的是别的站点的种子下载地址：这些站点要在 pt-tools 里已启用、配好了 Cookie，pt-tools 才能用自己的站点配置去下载。pt-tools 自己也有 [IYUU 辅种](reseed.md)。

## 能做什么

- **加种子**：上传种子文件，或者给站点的种子下载地址。
  - 种子文件按 tracker 认站点，认得出的会加上站点标签。
  - 下载地址只认已启用站点的地址：pt-tools 用自己的站点配置下载，不会去请求客户端给的地址。
  - 磁力链接不接受。
  - 选项：保存目录、分类、标签、暂停添加、改名与限速（和站点设置的限速取更严的）。
- **看种子**：种子列表、详情、文件、tracker、分类与标签，都是背后那台下载器里的全部种子。tracker 地址里的 passkey 会被遮住。
- **改种子**：暂停、继续、删除（可以连数据一起删）、改分类、加减标签。默认只能动经兼容入口加进这台下载器的种子（加的时候原来就在下载器里的不算；加完以后几秒内下载器里看不到的不算；经兼容入口删掉以后，同一个种子再从别处加回来也不算）。经兼容入口加的种子在下载器里带标签 `pt-tools-compat`（Transmission 是 label），客户端看不到也改不了；在下载器里去掉它以后，兼容入口不再把这个种子当成自己加的。打开「完全控制」以后，能动这台下载器里的全部种子。没有权限动的种子会被跳过：客户端看到的仍是成功，操作审计里记为被拒。

背后的下载器是 Transmission 时也能用，种子的状态、分类与标签会换成 qBittorrent 的写法。

qBittorrent 的其余接口（RSS、搜索、日志、修改设置、调整限速与优先级等）回 404。

## 登录与安全

- 用户名随意，密码是 API 令牌。同一 IP 在 15 分钟内登录失败 5 次，15 分钟内不能再登录。
- 登录以后的会话 1 小时没有请求就失效；令牌撤销或过期以后，会话立即失效。pt-tools 重启以后，客户端会自动重新登录。
- 这个端口只在内网开放：会话 Cookie 与令牌在纯 HTTP 下都可能被同一网络中的他人截获。监听在所有网卡上时，页面上也会提醒。
- 写操作与登录失败都记在「ChatOps → 操作审计」里，通道是「qB 兼容」。
