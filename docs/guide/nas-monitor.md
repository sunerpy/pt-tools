# NAS 监控 <Badge type="tip" text="1.0 预览版" />

「系统 → NAS 监控」管首页 [NAS 概览](home-and-health.md#nas-概览)的数据从哪来：pt-tools 所在的主机（本机来源）与接入的 NAS（现在能接入 [TrueNAS](#truenas)）。pt-tools 在后台定时读这些来源，读到的数据放在内存里；首页和这一页显示的都是内存里的数据，打开页面不会再去连一次。

## 本机来源

本机来源读 pt-tools 所在主机的 `/proc` 与 `/sys`：CPU 使用率、负载、IO 等待与 CPU 温度（主机有温度传感器时），内存，运行时长，以及主机名、CPU 型号与核数、内核版本。

- 只支持 Linux。在 Windows、macOS 上这一行写 `本机来源只支持 Linux`，开关不能打开。
- pt-tools 在 Docker 里时，读到的是宿主机的 CPU、内存与负载。
- 读不到网卡、存储池、硬盘与告警。首页的网络那张卡换成下载器速度，存储换成下载盘与媒体库所在的盘。
- 默认开着。关掉以后不再读，首页没有别的能显示的来源时是空状态卡。

## TrueNAS

接入 TrueNAS 25.04 或以后的版本。pt-tools 用一把只读的 API Key 连它的 JSON-RPC 接口（`wss://<地址>/api/current`），一条连接一直连着，连上时登录一次。读到的：

- 主机：主机名、版本、CPU 型号与核数、内存总量、运行时长与负载
- CPU 使用率与温度、内存；虚拟机里通常读不到 CPU 温度，首页的 CPU 卡写 `读不到温度`
- 网络：连着的物理网卡合计的收发速度
- 存储池：状态、健不健康与容量。容量按根数据集的已用与可用算，是扣掉校验盘以后能存的；读不到根数据集的池按裸容量算（含校验盘）
- 硬盘：型号、机械盘还是固态盘或 NVMe、大小、温度与所在的存储池；不读序列号
- 告警：在 TrueNAS 上没关掉的告警，常见的几类写成中文，其余用 TrueNAS 自己的说明
- 应用：运行中、共几个、几个可以更新

第一次连上时，把 TrueNAS 记下的最近 30 分钟的 CPU、内存与网络补进首页的柱子。

### 准备只读的 API Key

1. 在 TrueNAS 的「Credentials → Users」点「Add」，建一个只给 pt-tools 用的用户：打开「Disable Password」，「Auxiliary Groups」选 `truenas_readonly_administrators`（只读管理员），不勾「SMB User」，不给 sudo。
2. 在 TrueNAS 右上角的用户菜单点「My API Keys」→「Add」，「Username」选这个用户，保存后复制 Key。Key 只显示这一次，没复制到就在这把 Key 的编辑里点「Reset」重新生成。
3. 在 pt-tools 的「添加来源」里类型选 TrueNAS，地址写 TrueNAS 网页的 https 地址（例如 `https://192.168.1.10`，改过端口的写上端口），粘贴 Key，点「测试连接」。TrueNAS 默认用自签证书：核对证书的 SHA-256 指纹和 TrueNAS 上的一样以后，点「信任这张证书并再测一次」，连上了再保存。

- 只收 `https://` 地址。TrueNAS 会吊销经 http 用过的 API Key，pt-tools 不会经 http 发 Key。
- 只读管理员读得到这些数据，改不了设置：pt-tools 不会改 TrueNAS 上的任何东西，也不会关掉它的告警。
- Key 在 TrueNAS 上被删或吊销以后，这个来源变成 `登录失败`。重新建一把，编辑这个来源填上新的 Key。
- 版本早于 25.04 时，测试连接写 `这台 TrueNAS 没有 /api/current 接口（HTTP 404）：要 TrueNAS 25.04 或以后的版本`。

## 来源列表

每个来源一行（手机上一张卡）：

| 列         | 内容                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| 来源       | 名字、类型与地址（本机来源写 `pt-tools 所在的主机`）；实验性的类型带 `实验性`，用 `http://` 地址的带 `明文连接` |
| 读到的主机 | 主机名、CPU 型号与核数、内存总量、平台与版本；第一次读到以前写 `还没有读到数据`                                 |
| 状态       | 状态与下面一行说明，有问题时再写上次读到数据的时间                                                              |
| 操作       | 本机来源的开关；「重新连接」；接入的来源还有「编辑」「删除」                                                    |

| 状态           | 下面一行                                                               |
| -------------- | ---------------------------------------------------------------------- |
| `已连上`       | 多久以前更新的（`40 秒前更新`）                                        |
| `正在连`       | 读到数据以后显示                                                       |
| `连不上`       | 错误原文与下次什么时候再试（`30 秒后再试`）                            |
| `登录失败`     | 原因；改了设置或点「重新连接」以后才会再试                             |
| `证书不受信任` | 没有发出凭据就断开了：编辑这个来源，测试连接并确认证书                 |
| `证书换了`     | 证书和信任的那张不一样，没有发出凭据就断开了：编辑这个来源，确认新证书 |
| `已停用`       | 本机来源关着，或者接入的来源没勾「启用」                               |
| `用不了`       | 这个版本、这个平台用不了这种来源                                       |

连不上时按 30 秒、1 分钟、2 分钟、5 分钟再试；登录失败与证书的问题不自动重试（一直用错的密码登录，NAS 可能锁住这个账号），改了设置或点「重新连接」以后再试。「重新连接」马上试一次，不等下一次，结果写在提示里。

列表右上角的「添加来源」按类型给出要填的字段，选 TrueNAS 时上面写怎么准备只读的 API Key（见 [TrueNAS](#truenas)）；页面下方的说明写能接入哪些。

## 首页显示

「首页的 NAS 概览显示」选一个来源：

- **自动**（默认）：显示第一个能用的来源，没有时用本机。
- **本机**或某个来源：一直显示它。选的来源停用了或用不了时，首页先显示别的，下拉框下面写现在显示的是哪个。

改了马上保存，不用重启；首页下次取数据时就换过来。删掉首页正在显示的来源时改回自动。

## 读取的频率与保存

- 每个来源每 30 秒读一次 CPU、内存与网络，每 5 分钟读一次存储池、硬盘、告警与应用。
- 最近 30 分钟的数据只放在内存里（首页的柱子就是这些），pt-tools 重启以后重新读。
- 接入的来源的密钥与登录凭据加密存在数据库里，页面上不会显示。编辑时密钥留空就是不改；改了地址或账号时要重新填，原来的密钥不会发给新的地址。
- 来源用自签证书时，在「测试连接」里核对证书指纹以后信任，以后只认这一张；证书换了会停下来等你确认，不会把凭据发给换了证书的服务。

[系统体检](home-and-health.md#系统体检)的「NAS」一组看接入的来源：连没连上、存储池健不健康、有没有严重告警、硬盘热不热。它只看这里已经读到的数据，不再连一次 NAS。

App API、MCP 与手机 App 现在读不到 NAS 的数据，AI 助手的配置工具也改不了 NAS 监控的设置。
