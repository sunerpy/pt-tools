# 数据统计与每日战报

「用户统计」页汇总各站的上传、下载、分享率、魔力与做种数据。pt-tools 每天给每个站点存一份数据快照，用它算出每天、每周、每月的增量，在页面上画走势，也可以每天把当天的增量发到通知通道（每日战报）。

## 数据从哪里来

- 每次成功获取某站的用户数据时，pt-tools 更新这个站点的数据，同时写入当天的快照；同一天获取多次只保留最后一次。
- 探测模式为「自动」的站点，登录状态探测每 6 小时左右获取一次用户数据，快照随之更新（见[站点登录状态与密钥备份](site-login-monitoring.md)）。
- 探测模式为「手动」或「禁用」的站点，只在登录 Web 界面或点击「同步」时更新，不另外定时访问。
- 快照按服务器时区分日（Docker 里由 `TZ` 决定），保留 400 天，更早的每天自动清理。

## 增量怎么算

- 某天的增量 = 当天快照 − 上一份快照。中间有几天没有快照时，这份增量覆盖的是这几天的总和，不做插值。
- 周期增量（今日、本周、本月）= 周期内最新一份快照 − 周期开始前最近的一份快照；周期开始前没有快照时，用周期内最早的一份。只有一份快照的站点算不出增量。
- 站点数据回退（站点重置统计、兑换魔力）时，那一项的增量按 0 计，不计入合计。

## 页面上看哪里

| 位置                       | 内容                                                                   |
| -------------------------- | ---------------------------------------------------------------------- |
| 用户统计 → 工具栏「周期」  | 今日、本周（近 7 天）、本月（近 30 天）                                |
| 用户统计 → KPI「总上传量」 | 所选周期的上传增量；柱图是最近 7 天每天的上传增量                      |
| 用户统计 → 「上传构成」卡  | 所选周期上传增量最多的 6 个站点；还没有可比快照时按当前累计上传量排    |
| 站点列表（手机）           | 每张站点卡上的 8 根柱：最近 8 天每天的上传增量                         |
| 站点详情 → 「站点统计」卡  | 近 30 天上传增量与每天的走势                                           |
| 用户统计 → 导出            | 分享图可以附上周期增量（「附上周期增量」开关与周期选择），打码选项照旧 |

刚装好或刚开始同步时还没有历史快照，增量要等到第二天有了第二份快照才出现。

## 每日战报

在「系统设置」的「每日战报」里开启，设置发送时刻（默认 `22:00`，服务器时区）和接收通道。开启时至少要选一个通知通道，不会默认发到所有通道。

每天到了发送时刻，再错开一个本机固定的 1–10 分钟偏移（最晚当天 23:59），pt-tools 发一条当天的战报：

- 当天各站上传、下载、魔力的增量与合计，按上传排序最多列 10 个站点；
- 登录状态异常的站点（会话过期、密钥错误、被拦截、网络错误等）；
- 当天的签到结果（成功、已签、失败的站点数）；
- 数据回退、按 0 计入的站点。

战报只算已启用的站点；探测模式为「禁用」的站点不再探测，它残留的探测状态不算登录异常。还没有今天之前的快照、算不出增量时，战报写明「还没有可比的数据」，不报一排 0。

同一天每个通道只发一次，重启也不会重发。通道处在自己的静默时段时，战报顺延到静默结束再发；发送失败按 1、5、30 分钟重试。服务在发送时刻之后、当天结束之前启动，会补发当天的战报；整个发送时刻到午夜都没在运行的那一天不补发，第二天的战报也只算第二天的增量。

## 接口

| 接口                                                    | 说明                                   |
| ------------------------------------------------------- | -------------------------------------- |
| `GET /api/v2/userinfo/history?site=<站点>&days=<1–400>` | 某站最近若干天每天的数据与增量         |
| `GET /api/v2/userinfo/summary?range=today\|7d\|30d`     | 各已启用站点在周期内的增量与合计       |
| `GET /api/v2/userinfo/trends?days=<1–60>`               | 各已启用站点最近若干天每天的增量与合计 |
| `GET` / `PUT /api/v2/userinfo/daily-report`             | 读写每日战报设置                       |

这些接口都要求登录。
