# 追剧与订阅 <Badge type="tip" text="1.0 预览版" />

订阅一部电影、追一部剧集的一季以后，pt-tools 会到各站点搜索，RSS 里出现时也会下载：按质量档案挑出最合适的资源推送到下载器，下载完成后由[整理入库](media-library.md)放进媒体库。剧集是追剧：按 TMDB 上每一集的播出时间去搜，一集一集补齐，只要同一个制作组、同一个分辨率的版本；每次搜索找到了什么、为什么没要都记在运行记录里。打开洗版后还会接着找更好的版本，入库后替换旧版本。豆瓣「想看」可以自动建订阅。

入口在「媒体 → 探索」与「媒体 → 追剧与订阅」；种子搜索的结果里点「追剧」，可以从那个种子开始追。订阅要用 TMDB：发布的版本内置了 TMDB API Key，不用填；自己从源码编译的要先在[媒体识别](media-recognize.md#tmdb-api-key)里填。

## 开始之前

1. 在「媒体 → 追剧与订阅」最下面的「订阅设置」里打开「订阅」总开关。关着时不搜索、不看 RSS、不拉豆瓣，订阅列表上方会写明。
2. 主动搜索用的是站点的搜索，和「种子搜索」页一样：在那里能搜到的站点，订阅才搜得到。
3. 下载完成后要整理进媒体库，订阅才算入库：在「媒体 → 媒体库」里打开自动整理（见[整理入库](media-library.md)）。

## 建订阅

在「探索」页看 TMDB 的列表（本周趋势、热门、高分，电影还有正在上映、即将上映，剧集还有正在播出、今天播出）、[按国家与类型找](#探索)，或者按名字搜索，电影点「订阅」，剧集点「追剧」。已经订阅过的条目写着「已订阅」，库里已有的写着「已入库」。剧集要选季，不填时追最新一季；弹窗里写明 TMDB 上一共几季、要追的这一季几集。同一季只能有一个订阅，这一季已经在追时弹窗里写明，要追别的季再建一个。剧集还有追剧的设置，见下文「追剧」。点海报或名字打开[条目详情](media-detail.md)，看这一部的资料、库里有几集与下载过的种子。

| 选项               | 说明                                                                                                                                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 整理进哪个媒体库   | 电影与剧集都能选，只列同类型、启用着的库，见下文[整理进哪个媒体库](#整理进哪个媒体库)                                                                                                                             |
| 下载器             | 不选时用设置里的默认下载器，再没有时用 pt-tools 的默认下载器                                                                                                                                                      |
| 分类、标签         | 推送到下载器时带上                                                                                                                                                                                                |
| 保存目录           | 下载器里看到的路径，可以选下载器预设的目录，也可以直接输入；不填时用下载器的默认目录                                                                                                                              |
| 质量档案           | 按哪个档案挑资源；选「用设置里的默认档案」时跟着设置走，见下文「质量档案」                                                                                                                                        |
| 只在这些站点找     | 不选时是所有启用的站点                                                                                                                                                                                            |
| 标题包含、标题排除 | 对种子标题与副标题：填了包含词时含其中任一个才要，含任何一个排除词的不要；按行或逗号分开，不分大小写，空格、点、下划线当作一样。只要某个制作组的版本时填组名，例如 `CHDWEB`；要同时满足几个词时写标题里连着的一段 |
| 洗版               | 下载过以后接着找分数更高的版本，见下文「洗版」                                                                                                                                                                    |

新建时下载器、分类、标签与保存目录按选的媒体库（或「按类型自动选」选到的库）带出，输入框下面写明来自哪个库；自己改过的项换库也不变，见[新建订阅时带出的下载设置](media-library.md#新建订阅时带出的下载设置)。

### 试搜索

弹窗里「标题包含」下面的「试搜索」，按表单现在的质量档案、站点、标题包含与排除在站点上搜一次，结果在右侧打开（手机上占满屏幕）；不推送，也不保存订阅。新建和修改都能用，修改时按表单里改过、尚未保存的设置搜。慢的站点最多等 1 分钟。

结果分三栏：

- **符合条件**：没被质量档案、标题包含与排除、拉黑挡下的种子。符合条件不一定会下载，每一组写明能补上哪几集、这些集已经有了还是正在下载。
- **不符合**：写出全部原因，例如「标题含排除词 hdtv」；拉黑的写明拉黑了。
- **对不上这一季**（电影是「对不上这部电影」）：名字、年份或季对不上这个条目的种子，写明原因。

顶上写明这次搜的词（TMDB 上的名字）、用了多久、这一季缺哪几集，以及哪些站点出错。表单里开着版本锁、锁住了制作组与分辨率时，对不上锁的组标「版本锁不收」；尚未锁住时写明第一个下载成功的版本会成为锁。

结果上的操作只改表单，点「保存」（新建时是「开始追」「订阅」）以后才生效：

| 操作                       | 改什么                                                                                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 复制标题、复制副标题       | 复制一组里选中的种子的；一组里有几个站点的种子时，点一行选它                                                                                                                             |
| 只要「组名」、不要「组名」 | 在标题包含或标题排除里加一行组名；认出了制作组时才有                                                                                                                                     |
| 选标题里的一段…            | 标题按空格、点、下划线、括号切成小块，点这一段的第一块和最后一块（只要一块时点它两次），加进标题包含或排除。这一段里有集号（例如 `S02E03`、`第 3 集`）时提醒：加进标题包含以后只收这一集 |
| 锁这个版本                 | 剧集：打开版本锁，锁住这一组的制作组与分辨率。新建时一开始就锁住，不等第一个下载成功的版本                                                                                               |
| 保存时从这个种子开始追     | 新建剧集：建好以后马上推送这个种子（同[从一个种子开始追](#从一个种子开始追)），起始集设成它的第一集，整季包不改起始集；点「不从它开始」改回去                                            |

已经有的词不重复加；加了以后超过 1024 字节时不加，提示先删掉几个词。

改了表单以后，结果顶上提示「表单改过了」，点「再试一次」按新表单搜。站点的搜索结果缓存 10 分钟：只改标题包含、排除或质量档案再试很快，不会再去站点搜；有站点出错的那次不缓存，再试会重新去站点搜。

### 探索

「按国家与类型找」按出品国家或地区（中国大陆、中国香港、中国台湾、日本、韩国、美国、英国）与类型（动画、纪录片；剧集还有综艺，即 TMDB 的真人秀与脱口秀）列出 TMDB 上的电影或剧集，按热度排，两项都可以不限。TMDB 的列表与搜索结果缓存 6 小时。

「番剧日历」按星期列出 [Bangumi](https://bgm.tv) 每日放送里这一季在播的动画，默认是今天，数据缓存 6 小时。点一部时，pt-tools 用去掉「第二季」「第2期」「2nd Season」这类后缀的中文名与原名在 TMDB 上找这部剧：只要动画，首播年份不能晚于这一季开播的下一年；名字（中文名或原名）完全相同的只有一个时用它，没有完全相同的、名字互相开头的只有一个时也用它。找到了打开[条目详情](media-detail.md)，在那里追剧；拿不准或没找到时写明搜过的名字，点「按名字搜索」到 TMDB 上自己挑。

在机器人里也能订阅：发 `/sub 关键词`，回复列表里的编号；剧集可以在编号后加季号，例如回复 `2 3` 订第 2 个条目的第 3 季。`/follow 剧名`（也可以写 `/追剧`）只列剧集，按追剧的默认设置建。`/subs` 列出订阅的编号、进度与下次搜索的时间，`/runs 编号` 看最近几次运行。`/sub`、`/follow` 只有管理员能用，见 [ChatOps 快速开始](chatops-quickstart.md)。

列表写明每个订阅的进度、最近一次搜索或下载的结果，以及下次搜索的时间；追剧还画出每一集的小格子，写明定时与版本锁。在找的订阅可以「立即搜索」「暂停」；暂停的点「恢复」；豆瓣建出的待确认订阅点「确认」以后才开始找。「详情」列出每一集的情况、运行记录与下载过的种子。点订阅的名字打开这一部的[条目详情](media-detail.md)。「媒体 → 日历」按天列出订阅的集哪天播出，见[订阅日历](media-detail.md#订阅日历)。删除订阅不动下载器里的种子，也不动库里的文件。

## 追剧

剧集的订阅是追剧。从「探索」点「追剧」、从种子搜索的结果点「追剧」、在机器人里发 `/follow` 建的，默认按播出时间搜索、开着版本锁；以前建的剧集订阅和 `/sub`、豆瓣建的，保持原来的按全局间隔搜索，可以在「修改」里换成追剧的设置。

### 从一个种子开始追

种子搜索的结果里点「追剧」：pt-tools 先用这个种子的标题与副标题识别出是哪部剧、第几季（认错了可以在弹窗里改选），建好追剧以后马上推送这个种子，起始集默认是这个种子的集（不想要之前的集）。种子不合质量档案、这几集已经有了时不推，原因写在追剧的说明里；认出来不是这部剧、这一季的种子也不用。认不出是哪部剧时，可以先在[媒体识别](media-recognize.md)里纠正，或者去「探索」搜这部剧。

### 什么时候搜索

| 定时         | 说明                                                                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 按播出时间   | 默认。按 TMDB 上每一集的播出日期加「播出时刻」（pt-tools 所在机器的时区，默认 20:00）：播出后 2 小时开始搜，没找到每 6 小时再搜，播出 7 天以后仍没有就每天搜一次；没有要等的集时每天看一次 TMDB 有没有新的集 |
| 每隔一段时间 | 从上次搜索算起，每隔一段时间（30 分钟到 7 天，单位可选分钟、小时、天）搜一次                                                                                                                                 |
| 每天         | 每天到点搜一次                                                                                                                                                                                               |
| 每隔几天     | 从建好那天算，每隔几天（1 到 30）到点搜一次                                                                                                                                                                  |
| 每周、每月   | 选星期几或几号（小月没有的日子按月末），到点搜一次                                                                                                                                                           |
| cron 表达式  | 自己写什么时候搜，适合综艺这类固定在某几天、某几个钟点播的；写法见下面                                                                                                                                       |
| 按全局间隔   | 和电影一样按「订阅设置」里的间隔                                                                                                                                                                             |

cron 表达式是 5 段，用空格分开：`分 时 日 月 星期`。每段可以写 `*`（不限）、一个数、`1-5`（范围）、`*/2`（每隔 2 个）、`8,20`（几个）；星期的 0 和 7 都是星期日，也可以写 `MON`–`SUN`，月份可以写 `JAN`–`DEC`。几条用分号（或换行）分开，到点的取最早的一条；日与星期都限定时，满足一个就到点（和 crontab 一样）。也认 `@daily`、`@weekly`、`@monthly` 这类简写。几个例子：

| 写法                       | 什么时候搜                   |
| -------------------------- | ---------------------------- |
| `0 20 * * *`               | 每天 20:00                   |
| `0 8,22 * * *`             | 每天 8:00 与 22:00           |
| `0 22 * * 5,6`             | 周五、周六 22:00             |
| `0 22 * * 5; 0 9,13 * * 6` | 周五 22:00，周六 9:00、13:00 |
| `0 */2 * * 1-5`            | 工作日每 2 小时              |
| `0 9 1 * *`                | 每月 1 号 9:00               |

修改定时的时候，弹窗里会算出接下来几次什么时候搜；表达式写错时直接说哪一段不对。

播出后几小时开始搜、没找到隔几小时再搜、播出后几天里集中重试，都可以在「修改」里改。定时到点的搜索前后有几分钟的随机偏移；两次搜索至少隔 30 分钟。追剧的 TMDB 分集信息每 6 小时重新读一次，新加的集会自动排进来。

### 版本锁

开着版本锁时，第一个下载的版本定下来以后（制作组与分辨率，例如 `HHWEB 1080p`），后面的集只要同一个版本，同一季不会混着几个组的片源。尚未定下时，库里或下载中已有的那个版本就是锁住的版本。

从种子搜索的结果点「追剧」时，选中的那个种子没推成（例如种子文件被站点的 Cloudflare 质询拦了），锁也按它的版本定：点「重新搜索」时还要这个版本，不会换成分数更高的别的版本。

- 锁住的版本播出很久仍未出现：过了「播出后几天里集中重试」的天数，这一集显示「等版本」，接着等，默认不换别的版本；并按设置里的通道通知一次（之后最多每 3 天提醒一次）。站点上找到过锁住的版本、只是种子文件没下载下来的不算等版本，显示「缺」，接着找。
- 某一集要换别的版本：在追剧详情里点那一集「这一集换版本」，或者在机器人里发 `/unlock 编号 集号`。只放开这一集，一分钟内搜一次；其他集照旧。
- 不想一直等：在「订阅设置」里把「版本锁等满几天改用别的版本」设成天数（0 到 90，默认 0 是一直等）。一集「等版本」满这么多天、开始等以后至少搜过一次时，像点了「这一集换版本」一样只放开这一集，马上搜一次；运行记录里写明「按设置改用别的版本」。锁住的版本不变，其他集照旧按锁找，所以一季里可能混着两个版本。
- 原来的制作组不更新了：在「修改」里改锁住的版本。「最近一次搜索找到」列出这次搜到的、能补上缺的集的版本，写明各能补哪几集，点一个就改成它（尚未搜索时是空的，下一次搜索以后才有；要马上列出来，在列表里点「立即搜索」）；也可以自己填制作组和分辨率，留空一项就不限这一项（例如只填制作组，这个组的哪个分辨率都要）。两项都清空时，下一个下载成功的版本成为新锁住的版本，库里已有的集不动，也不再按它们定锁。改了以后很快按新的锁搜一次。
- 「修改」里也可以关掉版本锁。洗版换整季包时不受版本锁限制，换成的版本就是新锁住的版本。

### 每一集

追剧详情里每一集一个格子，状态是 `已入库`、`下载中`、`缺`（已播出、库里没有）、`等版本`、`还没播`（尚未播出）、`不追`（起始集以前的与跳过的）之一。点一集看名字、播出日期、现在的版本，可以「跳过这一集」（不追：不算缺，也不影响追完）或「重新要这一集」。

订阅用的下载器里已经有的这部剧的种子（不是订阅推送的，例如自己手动下的）也算进来，不会再下一份：有哪几集按种子里选中的文件认，种子名写成整季（有的站点一集一个种子、种子名却是季的目录名）或者季包只选了几集都一样；读不到文件列表时按种子名，写的是整季的先不算。这样的种子 7 天以后仍未整理入库，照样算失败、重新找：自动整理只处理 pt-tools 推送的种子，要手动整理它，或者在[整理入库](media-library.md)里打开定期扫描。

「修改」里可以改「从第几集开始追」（之前的集不要），TMDB 上的集数不对时可以手动填这一季的集数。

### 综艺的集号

不少综艺在 TMDB 上一期分成上下两集，而站点上的种子有的按 TMDB 的集号编，有的写「第 1 期下」「E01 Part 2」，有的只写播出日期（`20261002`、`1015期`）。pt-tools 认出这一季是按期编的（TMDB 的类型是真人秀、脱口秀，或一半以上的集名是「第几期」）时，按期号与上下、播出日期换算成 TMDB 的集号；拿不准的不要，运行记录里写「集号对不上」。标题写了集号、期号只在副标题里时，两边要对得上（副标题常有写错的），对不上的也不要；只有一种例外：副标题写的那一期按 TMDB 的播出进度还不可能播出（例如才播到第 3 期，副标题写第 5 期），而标题写的那一集已经播出，这时当作副标题把集号写成了期号，按标题的集号算。这样收下的种子推送成功以后，pt-tools 给这个制作组记一条「按 TMDB 的集号」的集号规则（来源显示「自动」），以后这个组都按标题的集号：季初副标题写的期离播出进度只差一期、季末 TMDB 列出了副标题写的那一期时，上面的例外判断不了。规则不对的话在「集号规则」里删掉。

某个制作组的编法换算不对时，在追剧详情的「集号规则」里给它设一条：按 TMDB 的集号、按第几期与上下、按播出日期，或者集号偏移（TMDB 的集号 = 标题里的集号 + 偏移）。组名不填的对所有组。设了规则以后一分钟内按它搜一次。

### 剧集组

TMDB 上一部剧除了默认的季集，还可能有别的排法（剧集组）：动画常见的绝对集号（第 25 集）、DVD 或播出时的分季。站点上的种子按别的排法写集号时，在追剧的「修改」里选这部剧的剧集组（TMDB 上这部剧没有剧集组时不显示这一项）：

- 种子标题与文件名里的季集先按剧集组换成 TMDB 默认的季集，再对种子、映射集号。只写了集号的（季当作 1）按剧集组的第 1 组算，例如绝对集号 25 换成第 2 季第 1 集。主动搜索时英文名后面不加季（种子按剧集组写集号，加了 TMDB 的季号搜不到）。
- 追剧的进度、日历与条目详情，以及整理进库的文件名与刮削，都按 TMDB 默认的季集。
- 剧集组里没有的集照 TMDB 默认的季集算，运行记录与整理记录里写明。订阅对种子时换算出的几集不连着的不用这个种子；整理时换算出的几集不在同一季或不连着的按文件名里的季集整理。
- 读不到剧集组时（TMDB 暂时不能访问），这一轮不用按剧集组对种子，整理稍后重试；剧集组在 TMDB 上删了时写明，在「修改」里换一个或改成不用。

### 运行记录

每次主动搜索、RSS 里对上、建立、手动改动（标成「改动」）各记一条：在哪些站点搜到几个、哪些种子为什么不要（不合质量档案、不是锁住的版本、集号对不上……）、推送了哪个。在追剧详情里点一条看经过；机器人里发 `/runs 编号`。每个订阅保留最近 100 条、不超过 90 天。

在找的订阅可以在运行记录上方点「立即搜索」。最近一次没成（失败，或者有种子推送失败）时按钮写成「重新搜索」：推送失败的种子没有记下，重新搜索时会再推一次。

### 下载过的种子

追剧详情最下面列出订阅下载过的种子，每个种子下面写明每个视频文件整理、刮削得怎样：已整理、失败（写明原因）、跳过，失败的是否在自动重试，整理好的刮削成功还是部分刮削。整季包与单集一样，一个种子一组按钮：

- 「重新整理」：种子里有整理没成、也不在自动重试的文件，或者种子 7 天没入库标成了失败时出现。按订阅的条目与媒体库整理这个种子（不靠识别），已经整理好的文件不动；标成失败的种子改回等整理，整理成了马上标成已入库。
- 「重新刮削」：有整理好的文件时出现。按媒体库现在的刮削设置重写这部剧（或电影）的 NFO 与图片，和整理历史里的「重新刮削」一样。
- 「不要这个种子」：站点上下的种子都有（下载器里认领的没有）。拉黑这个种子，见下文[拉黑的种子](#拉黑的种子)。

几个操作都记进运行记录。洗版换掉的旧版本没有「重新整理」「重新刮削」。单个文件也可以在「媒体 → 整理历史」里重试、重新刮削。

### 追完以后

要追的集（起始集以后、没跳过的）都入库以后，追剧标成完成。之后 30 天内 TMDB 上这一季又有了已播出的集（加更、特别篇编进了这一季），会自动改回在找。打开「追完以后接着追下一季」的，一年内 TMDB 上下一季有了播出日期，就按这一季的设置建下一季的追剧（版本锁照开，锁住的版本重新定）。

### 整理进哪个媒体库

新建与修改时都可以指定媒体库，电影的订阅也可以；下拉只列同类型、启用着的库。指定了库时，推送的种子与算进来的下载器里的种子整理时都进这个库，不按类型自动选。指定的库后来删了、关了，或者类型和条目不同时，整理会失败并写明，在订阅里改选媒体库。

选「按类型自动选」时保存的是自动，整理时再按类型选，以后加了动画库也会用上。新建时它写明现在会整理进哪个库，没有启用的同类型媒体库时写明整理会失败。新建时下载设置也按这个库带出，见[新建订阅时带出的下载设置](media-library.md#新建订阅时带出的下载设置)。

这些种子整理时也按订阅的条目，不靠种子名识别（整理历史里写「按订阅的条目」）：种子名认不出或认成了别的剧，照样整理进这部剧。之前手动纠正过、整理过的文件仍按那时的条目。订阅推送时还会把条目记在种子上，订阅删了以后照样按它整理。

## 怎么找资源

订阅有两个来源，结果合在一起挑：

- **RSS**：已有的 [RSS 订阅](rss-subscription.md)拉到种子、取到详情以后，也拿来对一遍订阅。这和 RSS 自己的过滤规则互不影响：对上了订阅的种子由订阅推送。
- **主动搜索**：电影与按全局间隔的剧集按「主动搜索的间隔」搜一次（默认 12 小时，最少 6 小时，每次另加最多 30 分钟的随机偏移，避免所有订阅同时搜）；追剧按自己的定时（见上文「追剧」）。先用英文名或原名搜（电影加年份，剧集加季，如 `The Last of Us S02`；选了[剧集组](#剧集组)的剧集不加季），再用中文名搜。订阅限定了站点时只在那些站点搜；设置里「不参与主动搜索的站点」只看 RSS。

想自己看看各站点现在有哪些版本、挑一个推送时，用种子搜索的[按条目搜索](torrent-search.md#按条目搜索)：搜法和对条目的规则与这里一样，按订阅的质量档案打分，写明每个资源能补上哪几集。

改订阅的标题包含、排除或质量档案以前想先看看会收哪些种子，在订阅弹窗里点[试搜索](#试搜索)。

种子对上订阅的规则：

- 种子与订阅都有 IMDb 编号时，只看编号是否相同。
- 否则种子标题解析出的中文名或英文名，要和订阅的名字、原名或 TMDB 上的别名之一相同（去掉空格与标点、不分大小写）。识别词照样套用。
- 电影的年份差不超过一年；只按名字对时，种子（标题或副标题）要写了年份，同名不同年份的电影很多。写了季与集的不算电影。
- 剧集的季要对上；多季合集里有这一季也算。只写了集的动画（如 `- 05`）当作第 1 季。剧集不比年份：综艺的种子常写播出的年份，和 TMDB 上这一季的年份不同。

挑中的种子经和 RSS 一样的推送放进下载器：磁盘空间保护、站点做种容量这些限制照常生效，种子记录的来源写「订阅」。同一个订阅里同一个种子只推一次；推送失败（包括被磁盘空间保护、站点做种容量拦下）的不记下，下次搜索还会再试。

下载种子文件时遇到一时的网络错误（连接被重置、超时）或站点出错（5xx），按指数退避重试两次（约 2 秒、4 秒，每次先等站点的限速）：所有站点都这样，M-Team、NexusPHP 这类先取下载地址的只重拉那个地址。同一站点在一轮里连着两次没下载到，这一轮先不再从它下载。一轮最多推 10 个，没推成的也算。有种子文件没下载下来、推满了还有缺的集、手动搜索的时间用完了，下次搜索提前到 30 分钟以后，仍未全部完成时间隔翻倍（1、2、4 小时）；平常的下次时间更早时按平常的。RSS 送来的种子文件没下载下来，也这样提前主动搜一次。

## 下载前让 AI 复核

在「订阅设置」里打开「下载前让 AI 复核」（默认关），推送订阅找到的种子以前，pt-tools 把订阅的名字、原名、年份（剧集是这一季开播的年份）、季与别名，以及种子的标题、副标题与解析出的信息（剧集还写对到了第几季第几集）交给 [AI 助手](assistant.md)的模型，问它这个种子是不是这部片（剧集还要是这一季），只要「是」或「不是」加一句理由。要先在「AI 助手设置」里配好模型并启用。

- 范围默认「只复核按名字对上的」：种子与订阅都有 IMDb 编号、按编号对上的不问；选「全部」时每个要推送的种子都问。
- 说「不是」的种子这一轮不推，运行记录里写「AI 复核：不是，理由」，接着看下一个候选（整季包都说不是时一集一集补）；说「是」的照常推送，运行记录里写理由与用了多少 token。
- 模型出错（助手没启用、连不上、30 秒内没有回答）时照常推送，运行记录写「AI 复核没做成：原因」，这一轮后面的候选不再复核；回答看不出是还是不是时，只是这一个照常推送。
- 每次运行最多问 10 个，问满了剩下的候选下次再看（30 分钟后提前搜一次）。同一个订阅、同一个种子的结论记 24 小时，不重复问（pt-tools 重启以后重新问）。
- [从一个种子开始追](#从一个种子开始追)时自己选的种子不复核。

每个要推送的种子都要等模型回答，会用掉 AI 助手的 token。

## 按条目建子目录

在「订阅设置」里打开「下载时按条目建子目录」（默认关），订阅推送的种子放进保存路径下按条目起名的一级子目录，例如 `/downloads/最后生还者 (2023)`：

- 保存路径是订阅填的；没填时是下载器的默认保存路径（qBittorrent 设置里的默认保存路径、Transmission 的 download-dir）。读不到下载器的默认保存路径时这次不建子目录，写进运行记录。
- 子目录名的模板默认是 `{title} ({year})`，可以用 `{title}`（标题）、`{original_title}`（原名）、`{year}`（年份，剧集是首播年份）、`{season}`（季）与 `{tmdb_id}`。不知道的变量是空的，空括号去掉，名字里不能用的字符换掉；算出是空的时不建子目录。
- 下载器照这个目录放：qBittorrent 推送时另外传 `autoTMM=false`，这几个种子不用自动管理（开着自动管理时 qBittorrent 会忽略保存路径）；Transmission 本来就按 download-dir。
- 按条目搜索的推送弹窗里也有「按条目建子目录」，默认跟这个开关，用同一个模板，见[按条目搜索](torrent-search.md#按条目搜索)。
- 整理入库按下载器给的内容路径读，不受影响。自动整理限了「保存路径」时，范围要包含这些子目录，见[触发方式](media-library.md#触发方式)。

## 质量档案

质量档案在「追剧与订阅」页的「质量档案」里添加。一个订阅用一个档案；不建档案时按分辨率与来源从好到差挑。

| 项目               | 说明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 分辨率、来源、编码 | 按选的先后排偏好，排在前面的分数高；选了以后不在里面的不要，不选不限 |
| Remux、HDR         | 不限、优先、必须有、不要                                             |
| 中字、免费         | 不限、优先、必须有。中字看标题与副标题里有没有写                     |
| 偏好的制作组       | 加分，不是必须                                                       |
| 体积               | 最小、最大（GB，0 不限）。剧集按每集算：整季包按这一季的集数平均     |
| 最少做种数         | 只对搜索到的种子生效：RSS 里刚发布的种子做种数没有意义               |
| 不要 H&R           | 不要有 H&R 要求的种子（站点整站都有 H&R 的也算）                     |

打分：先过上面的硬条件，再依次比分辨率、来源、编码，前一项好的排在前面，后面的项不再比；这三项都一样时，Remux、HDR、中字（选了优先时）与偏好的制作组各加一点。分数相同时，档案选了「免费优先」的免费先，再看做种数，最后体积小的先。

## 剧集

剧集的进度按 TMDB 这一季的分集算：已经整理入库的、正在下载的、缺的（已经播出但不在库里）、在等锁住的版本的、未播出的、不追的。

- 播出期间一集一集补缺的集，每集挑分数最高的。
- 这一季播完以后，缺一半以上，或者缺的集找不到单集资源时，下载整季包。播出期间不下整季包：那时的整季包多半不全。
- 整季包（或一个种子里有几集）补缺的集时只下缺的集：推送以后在下载器里把库里已有、正在别处下载和不追的集的视频文件设成不下载（qBittorrent、Transmission 都支持），整理时这些文件跳过；种子里一集缺的都没有时不下载。下载器不支持或设置失败时整个种子照常下，运行记录里写明。开着洗版的订阅仍下整个包：库里已有的集也按每一集比版本。
- 订阅下载的种子有文件整理入库、其余文件也不再自动重试以后算入库；整季包有几集没整理成时写明，这几集算缺的，之后的搜索会再找。
- 订阅下载的种子过了 7 天仍未整理入库，就标成失败，这些集重新算缺的，之后的搜索会再找。
- 这一季要追的集都播完、都入库以后，订阅标成完成（追剧见上文「追完以后」）。电影整理入库以后完成；在「媒体库」里配了媒体服务器时，媒体服务器上已有这部电影也算完成。不洗版的电影订阅，库里已经有这部电影时不再下载。

## 洗版

打开洗版的订阅，下载过以后接着找分数更高的版本，直到库里的版本达到档案里排第一的分辨率与来源（档案选了「Remux 优先」时还要是 Remux；剧集要每一集都达到）。档案里没有排分辨率与来源时，下载一次就停。

- 比的是现在的版本：库里这个条目已有的文件（不是订阅下载的、[导入的已有文件](media-library.md#导入已有的媒体库)也算），以及订阅下载中、已入库的种子。分数按现在的档案重算，改了档案也能比；下载失败的不算。
- 电影：搜到分数更高的版本就下载；上一个版本还在下载时先不推新的。
- 剧集：这一季都在库里以后只换整季包，要至少有一集比现在的版本好；比整季包好的集入库以后留着。
- 新版本整理入库后，库里被它盖住、分数不比它高的旧文件（同分的也换，库里不留两份）按[整理历史](media-library.md#整理历史)的删除规则删掉：只删确认是 pt-tools 放进去的那份，移动整理的文件、导入的已有文件不删（导入的那条记录照旧是已整理）。旧记录改成「已删除」并写明换成了哪个版本。剧集只换新种子真正整理进库的集：整季包有几集没整理成时，这几集的旧文件留着；旧文件是几集的合集时，这几集新版本都有才换。新旧版本整理成同一个文件名时，新版本分数更高才先删掉旧版本再整理新版本（新版本没整理成时把旧版本整理回来），同分时旧的留着。旧版本是导入的已有文件时不删，新版本整理时跳过，见[导入已有的媒体库](media-library.md#导入已有的媒体库)。
- 订阅下载的旧种子在库里的文件都换掉以后按设置处理：继续做种（默认），或者连数据删掉。推送时下载器里已经有的种子（不是订阅加进去的）与有 H&R 要求的种子留着。

## 拉黑的种子

不想要的种子拉黑以后，订阅不再选它：RSS 送来的与主动搜索搜到的都跳过，运行记录里写「已拉黑：原因」。拉黑按条目记（剧集是这一季），删了订阅再建照样有效；在关键字搜索里拉黑的对所有订阅生效。在哪里拉黑见[种子搜索](torrent-search.md#拉黑)。

在追剧详情「下载过的种子」里点「不要这个种子」：

- 可以写一句原因；能勾「以后也不要这个种子的制作组」，把种子名里的制作组加进这个订阅的标题排除词（已经有的不重复加）。
- 这个种子还在下载时改成失败，写明「不要这个种子：原因」，这几集重新算缺的，马上再找资源；已经整理进库的文件不动。
- 可以勾「同时从下载器删掉这个种子」，再勾一项连同已下载的文件一起删；删以前再确认一次。
- 拉黑了的种子标「已拉黑」，标成失败的不能「重新整理」（重新整理会把它改回下载中）。要整理先移出黑名单。

「追剧与订阅」页的「拉黑的种子」列出全部拉黑的种子：种子名、站点与编号、作用于哪个条目（关键字搜索里拉黑的写「所有条目」）、原因与时间，点「移出」以后订阅又会选它。

## 豆瓣想看

在「追剧与订阅」页的「豆瓣想看」里添加豆瓣用户编号，也就是个人主页地址 `douban.com/people/` 后面那一段。收藏要公开：拉想看时 pt-tools 只拉豆瓣公开的「收藏」RSS，不登录豆瓣，也不调用非公开接口。

- 每 6 小时（另加最多 30 分钟的随机偏移）拉一次，只取「想看」的电影与剧集；读书、音乐，以及在看、看过的都不算。
- 按名字（和豆瓣给的原名）到 TMDB 找对应的条目。剧集按标题里写的季（如「第二季」），没写时订第 1 季。已经有订阅的条目只记下，不重复建。
- 打开「先确认」时，建出的订阅先是「待确认」，在订阅列表里点「确认」以后才开始找。
- TMDB 上找不到的条目记成「没找到条目」，之后不再去搜；可以到「探索」页自己搜了订阅。
- 用户删掉豆瓣建的订阅以后，这个条目写明「订阅已删除」，不会再建回来；条目从豆瓣的 RSS 里消失时，已经建的订阅也不删。
- 拉取失败时按 1、2、4…小时退避，最长 24 小时；连续 3 次失败标成「异常」，并按设置里选的通道通知一次。没有能用的 TMDB API Key 时整次算失败，条目不会被记成没找到。
- 「立即拉取」马上拉一次（这个来源正在拉取时提示稍后再试）；「条目」列出见过的条目与结果。删除来源时已经建的订阅留着。

## 通知

在「订阅设置」里选择通道后，下载了订阅的资源时发一条：订阅的名字（剧集带季）、种子、站点、集、画质，最后是 TMDB 的海报地址。追剧发「追剧更新」，多写锁住的版本；锁住的版本久等不到时发「追剧等版本」（带 `/unlock` 的写法）；连续 3 次没搜成（例如站点都超时）时发「追剧出错」。豆瓣来源变成异常时也通知一次。打开「今日更新」以后，每天到点推送今天播出的集与上映的电影，见[今日更新](media-detail.md#今日更新)。通知按通道的静默时段延后，失败时自动重试；文字可以在[消息模板](notify-channels.md)里改。

## 常见问题

**主动搜索一直搜不到**：先在「种子搜索」页用同样的名字试试，确认站点能搜到。订阅列表的「最近一次」写着每次的结果；只写「没有找到对得上的资源」时，多半是站点上种子的名字和 TMDB 上的写法不一样，可以在[媒体识别](media-recognize.md)里加识别词。

**找到了但没下载**：「最近一次」会写明哪些种子不符合质量档案以及原因（例如「分辨率 1080p 不在档案里」）。放宽档案，或者给这个订阅换一个档案。

**下载了但订阅一直没完成**：订阅要等文件整理入库。在追剧详情的「下载过的种子」里看每个文件整理得怎样，没整理成的写明了原因；改好（例如设了路径映射、换了媒体库）以后点「重新整理」。自动整理没打开时，下载完成的种子不会整理。

**追剧一直显示「等版本」**：锁住的制作组尚未发布这一集，或者不再更新了。在追剧详情里点那一集「这一集换版本」只放开这一集；整季都换的话，在「修改」里清掉锁住的版本；想等几天以后自动换，在「订阅设置」里设「版本锁等满几天改用别的版本」。

**综艺的集对不上**：看运行记录里被拒的种子写的原因。写「集号对不上」的，在追剧详情的「集号规则」里给那个制作组设一条（例如按第几期与上下）。加标题包含词收不下这样的种子：集号在标题关键词之前检查。
