# 订阅

订阅一部电影或剧集的一季以后，pt-tools 会定时到各站点搜索，RSS 里出现时也会下载：按质量档案挑出最合适的资源推送到下载器，下载完成后由[整理入库](media-library.md)放进媒体库。剧集按 TMDB 的分集补齐缺的集；打开洗版后还会接着找更好的版本，入库后替换旧版本。豆瓣「想看」可以自动建订阅。

入口在「媒体 → 探索」与「媒体 → 订阅」。订阅要用 TMDB，先在[媒体识别](media-recognize.md)里填好 TMDB API Key。

## 开始之前

1. 在「媒体 → 订阅」最下面的「订阅设置」里打开「订阅」总开关。关着时不搜索、不看 RSS、不拉豆瓣，订阅列表上方会写明。
2. 主动搜索用的是站点的搜索，和「种子搜索」页一样：在那里能搜到的站点，订阅才搜得到。
3. 下载完成后要整理进媒体库，订阅才算入库：在「媒体 → 媒体库」里打开自动整理（见[整理入库](media-library.md)）。

## 建订阅

在「探索」页看 TMDB 的本周趋势、热门，或者按名字搜索，点条目下面的「订阅」。已经订阅过的条目写着「已订阅」，库里已有的写着「已入库」。剧集要选季，不填时订最新一季；同一季只能有一个订阅，要订别的季再建一个。

| 选项           | 说明                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| 质量档案       | 按哪个档案挑资源；选「用设置里的默认档案」时跟着设置走，见下文「质量档案」 |
| 只在这些站点找 | 不选时是所有启用的站点                                                     |
| 下载器         | 不选时用设置里的默认下载器，再没有时用 pt-tools 的默认下载器               |
| 分类、标签     | 推送到下载器时带上                                                         |
| 保存目录       | 下载器里看到的路径；不填时用下载器的默认目录                               |
| 洗版           | 下载过以后接着找分数更高的版本，见下文「洗版」                             |

在机器人里也能订阅：发 `/sub 关键词`，回复列表里的编号；剧集可以在编号后加季号，例如回复 `2 3` 订第 2 个条目的第 3 季。`/subs` 列出订阅与进度。`/sub` 只有管理员能用，见 [ChatOps 快速开始](chatops-quickstart.md)。

「订阅」页的列表写明每个订阅的进度、最近一次搜索或下载的结果，以及下次搜索的时间。在找的订阅可以「立即搜索」「暂停」；暂停的点「恢复」；豆瓣建出的待确认订阅点「确认」以后才开始找。「详情」列出剧集每一集的情况与下载过的种子。删除订阅不动下载器里的种子，也不动库里的文件。

## 怎么找资源

订阅有两个来源，结果合在一起挑：

- **RSS**：已有的 [RSS 订阅](rss-subscription.md)拉到种子、取到详情以后，也拿来对一遍订阅。这和 RSS 自己的过滤规则互不影响：对上了订阅的种子由订阅推送。
- **主动搜索**：每个订阅按「主动搜索的间隔」搜一次（默认 12 小时，最少 6 小时，每次另加最多 30 分钟的随机偏移，避免所有订阅同时搜）。先用英文名或原名搜（电影加年份，剧集加季，如 `The Last of Us S02`），再用中文名搜。订阅限定了站点时只在那些站点搜；设置里「不参与主动搜索的站点」只看 RSS。

种子对上订阅的规则：

- 种子与订阅都有 IMDb 编号时，只看编号是否相同。
- 否则种子标题解析出的中文名或英文名，要和订阅的名字、原名或 TMDB 上的别名之一相同（去掉空格与标点、不分大小写）。识别词照样套用。
- 电影的年份差不超过一年；只按名字对时，种子（标题或副标题）要写了年份，同名不同年份的电影很多。写了季与集的不算电影。
- 剧集的季要对上；多季合集里有这一季也算。只写了集的动画（如 `- 05`）当作第 1 季。

挑中的种子经和 RSS 一样的推送放进下载器：磁盘空间保护、站点做种容量这些限制照常生效，种子记录的来源写「订阅」。同一个订阅里同一个种子只推一次；推送失败（包括被磁盘空间保护、站点做种容量拦下）的不记下，下次搜索还会再试。

## 质量档案

质量档案在「订阅」页的「质量档案」里添加。一个订阅用一个档案；不建档案时按分辨率与来源从好到差挑。

| 项目               | 说明                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 分辨率、来源、编码 | 按选的先后排偏好，排在前面的分数高；选了以后不在里面的不要，不选不限 |
| Remux、HDR         | 不限、优先、必须有、不要                                             |
| 中字、免费         | 不限、优先、必须有。中字看标题与副标题里有没有写                     |
| 偏好的制作组       | 加分，不是必须                                                       |
| 体积               | 最小、最大（GB，0 不限）。剧集按每集算：整季包按这一季的集数平均     |
| 最少做种数         | 只对搜索到的种子生效：RSS 里刚发布的种子做种数没有意义               |
| 不要 H&R           | 不要有 H&R 要求的种子（站点整站都有 H&R 的也算）                     |

打分：先过上面的硬条件，再依次比分辨率、来源、编码，前一项好的排在前面，后面的项不再比；这三项都一样时，Remux、HDR、中字（选了优先时）与偏好的制作组各加一点。分数相同时，档案选了「免费优先」的免费先，再看做种数，最后体积小的先。

## 剧集

剧集的进度按 TMDB 这一季的分集算：已经整理入库的、正在下载的、缺的（已经播出但不在库里）、未播出的。

- 播出期间一集一集补缺的集，每集挑分数最高的。
- 这一季播完以后，缺一半以上，或者缺的集找不到单集资源时，下载整季包。播出期间不下整季包：那时的整季包多半不全。
- 订阅下载的种子有文件整理入库、其余文件也不再自动重试以后算入库；整季包有几集没整理成时写明，这几集算缺的，之后的搜索会再找。
- 订阅下载的种子过了 7 天仍未整理入库，就标成失败，这些集重新算缺的，之后的搜索会再找。
- 这一季都播完、都入库以后，订阅标成完成。电影整理入库以后完成；在「媒体库」里配了媒体服务器时，媒体服务器上已有这部电影也算完成。不洗版的电影订阅，库里已经有这部电影时不再下载。

## 洗版

打开洗版的订阅，下载过以后接着找分数更高的版本，直到库里的版本达到档案里排第一的分辨率与来源（档案选了「Remux 优先」时还要是 Remux；剧集要每一集都达到）。档案里没有排分辨率与来源时，下载一次就停。

- 比的是现在的版本：库里这个条目已有的文件（不是订阅下载的也算），以及订阅下载中、已入库的种子。分数按现在的档案重算，改了档案也能比；下载失败的不算。
- 电影：搜到分数更高的版本就下载；上一个版本还在下载时先不推新的。
- 剧集：这一季都在库里以后只换整季包，要至少有一集比现在的版本好；比整季包好的集入库以后留着。
- 新版本整理入库后，库里被它盖住、分数不比它高的旧文件（同分的也换，库里不留两份）按[整理历史](media-library.md#整理历史)的删除规则删掉：只删确认是 pt-tools 放进去的那份，移动整理的文件不删。旧记录改成「已删除」并写明换成了哪个版本。剧集只换新种子真正整理进库的集：整季包有几集没整理成时，这几集的旧文件留着；旧文件是几集的合集时，这几集新版本都有才换。新旧版本整理成同一个文件名时，先删掉旧版本再整理新版本。
- 订阅下载的旧种子在库里的文件都换掉以后按设置处理：继续做种（默认），或者连数据删掉。推送时下载器里已经有的种子（不是订阅加进去的）与有 H&R 要求的种子留着。

## 豆瓣想看

在「订阅」页的「豆瓣想看」里添加豆瓣用户编号，也就是个人主页地址 `douban.com/people/` 后面那一段。收藏要公开：pt-tools 只拉豆瓣公开的「收藏」RSS，不登录豆瓣，也不调用非公开接口。

- 每 6 小时（另加最多 30 分钟的随机偏移）拉一次，只取「想看」的电影与剧集；读书、音乐，以及在看、看过的都不算。
- 按名字（和豆瓣给的原名）到 TMDB 找对应的条目。剧集按标题里写的季（如「第二季」），没写时订第 1 季。已经有订阅的条目只记下，不重复建。
- 打开「先确认」时，建出的订阅先是「待确认」，在订阅列表里点「确认」以后才开始找。
- TMDB 上找不到的条目记成「没找到条目」，之后不再去搜；可以到「探索」页自己搜了订阅。
- 用户删掉豆瓣建的订阅以后，这个条目不会再建回来；条目从豆瓣的 RSS 里消失时，已经建的订阅也不删。
- 拉取失败时按 1、2、4…小时退避，最长 24 小时；连续 3 次失败标成「异常」，并按设置里选的通道通知一次。没有填 TMDB API Key 时整次算失败，条目不会被记成没找到。
- 「立即拉取」马上拉一次（这个来源正在拉取时提示稍后再试）；「条目」列出见过的条目与结果。删除来源时已经建的订阅留着。

## 通知

在「订阅设置」里选择通道后，下载了订阅的资源时发一条：订阅的名字（剧集带季）、种子、站点、集、画质，最后是 TMDB 的海报地址。豆瓣来源变成异常时也通知一次。通知按通道的静默时段延后，失败时自动重试。

## 常见问题

**主动搜索一直搜不到**：先在「种子搜索」页用同样的名字试试，确认站点能搜到。订阅列表的「最近一次」写着每次的结果；只写「没有找到对得上的资源」时，多半是站点上种子的名字和 TMDB 上的写法不一样，可以在[媒体识别](media-recognize.md)里加识别词。

**找到了但没下载**：「最近一次」会写明哪些种子不符合质量档案以及原因（例如「分辨率 1080p 不在档案里」）。放宽档案，或者给这个订阅换一个档案。

**下载了但订阅一直没完成**：订阅要等文件整理入库。看「媒体 → 整理历史」里有没有这个种子的记录；自动整理没打开时，下载完成的种子不会整理。
