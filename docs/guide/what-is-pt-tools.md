# pt-tools 是什么

本页介绍 pt-tools 的用途、工作方式和 Web 界面中的各个页面，帮助你判断它是否适合自己。

pt-tools 是一个自托管的 PT（Private Tracker）站点管理工具。它在你自己的服务器、NAS 或电脑上运行，把多个 PT 站点、下载器和聊天通知放进同一个 Web 界面：定时拉取 RSS 订阅并把符合条件的种子推送到下载器，刷流、辅种和转移做种，把下载完的影视整理进媒体库，汇总各站点的用户数据和登录状态，并且可以通过手机 App、QQ 或 Telegram 查看和控制。

## 工作方式

pt-tools 是一个独立的程序，Web 界面和后台任务在同一个进程里运行，数据保存在本机的 SQLite 数据库中，不依赖任何托管服务。

- **站点**：你添加的每个 PT 站点都使用你自己的 Cookie、API Key 或 Passkey 访问。当前内置 66 个站点，见[支持站点](../sites.md)。
- **RSS 订阅**：后台按设定的间隔拉取订阅，按过滤规则或免费状态筛选种子，再推送到下载器。
- **下载器**：支持 qBittorrent 和 Transmission，可以同时添加多个。推送前会检查剩余空间和站点的做种数量上限。
- **做种**：刷流任务按条件挑新种做种、按规则删种；IYUU 辅种让同一份数据在多个站点做种；转移做种把种子搬到另一台下载器。
- **媒体库**：订阅电影与剧集，下载完以后识别、按模板放进媒体库并通知 Emby、Jellyfin 或 Plex。
- **通知与 ChatOps**：推送结果和系统事件可以发到聊天软件；绑定过的聊天账号可以发送命令，也可以和 AI 助手对话。
- **手机 App 与接口**：手机 App 经远程访问连回 pt-tools；脚本、MCP 客户端和其他工具可以用 API 令牌或 qB 兼容入口接入。

其中刷流、辅种、转移做种、媒体库、手机 App、AI 助手等是 1.0 预览版加入的功能，正式版 0.48.0 尚未包含，见 [1.0 预览版新功能](whats-new-1.0.md)。

| 媒体    | 探索、订阅、媒体库、整理历史、媒体识别                                                                          | 订阅电影与剧集；设置媒体库与整理规则；查看整理结果；纠正识别结果                                               |

## 适合谁

- 在多个 PT 站点刷流或追剧，需要按规则自动下载的用户。
- 希望同一份数据在多个站点做种，或者把下载完的影视自动整理进媒体库的用户。
- 希望在一个页面查看各站点数据、并在长期未登录之前收到提醒的用户。
- 已经在使用 qBittorrent 或 Transmission，希望统一管理多个下载器的用户。

## 使用前请注意

- pt-tools 使用你自己的账号凭证访问站点。启用自动访问前，请确认各站点的规则允许，并合理设置请求频率。pt-tools 不保证自动化访问不会被站点警告或封禁。
- 数据目录中的 `secret.key` 用来加密站点 Cookie。丢失密钥后，已保存的 Cookie 无法恢复，请与数据库一起备份，见[升级与备份](upgrade.md)。
- 不提供 macOS 二进制；macOS 请使用 Docker 运行。
