# pt-tools 是什么

本页介绍 pt-tools 的用途、工作方式和 Web 界面中的各个页面，帮助你判断它是否适合自己。

pt-tools 是一个自托管的 PT（Private Tracker）站点管理工具。它在你自己的服务器、NAS 或电脑上运行，把多个 PT 站点、下载器和聊天通知放进同一个 Web 界面：定时拉取 RSS 订阅并把符合条件的种子推送到下载器，汇总各站点的用户数据和登录状态，并且可以通过 QQ 或 Telegram 查看和控制。

## 工作方式

pt-tools 是一个独立的程序，Web 界面和后台任务在同一个进程里运行，数据保存在本机的 SQLite 数据库中，不依赖任何托管服务。

- **站点**：你添加的每个 PT 站点都使用你自己的 Cookie、API Key 或 Passkey 访问。当前内置 66 个站点，见[支持站点](../sites.md)。
- **RSS 订阅**：后台按设定的间隔拉取订阅，按过滤规则或免费状态筛选种子，再推送到下载器。
- **下载器**：支持 qBittorrent 和 Transmission，可以同时添加多个。推送前会检查剩余空间和站点的做种数量上限。
- **通知与 ChatOps**：推送结果和系统事件可以发到聊天软件；绑定过的聊天账号可以发送命令。

## 界面中的页面

左侧导航按用途分成几组。

| 分组    | 页面                                                    | 用途                                                                     |
| ------- | ------------------------------------------------------- | ------------------------------------------------------------------------ |
| 概览    | 用户统计、数据导出                                      | 所有站点的上传量、分享率、做种和等级进度；把统计导出为分享图             |
| 站点    | 站点列表、已支持站点                                    | 添加和配置站点、查看登录状态；浏览内置站点及其认证方式                   |
| 下载    | 种子搜索、任务列表、暂停任务、下载器 Web UI、下载器设置 | 跨站点搜索并推送种子；查看 RSS 推送记录；管理下载器中的任务和下载器配置  |
| 规则    | 过滤规则、自动清理                                      | 编写 RSS 过滤规则；配置自动删种、磁盘保护和工作目录清理                  |
| ChatOps | 消息通知、ChatOps 绑定、操作审计、RSS 通知日志          | 配置通知通道；绑定聊天账号；查询命令记录和 RSS 通知的发送结果            |
| 系统    | 全局设置、CloakBrowser、运行日志、修改密码              | 运行间隔、下载策略等全局配置；可选的登录探测后备通道；查看日志；修改密码 |

在手机上，同样的页面以卡片形式显示，底部导航提供常用入口。

## 适合谁

- 在多个 PT 站点刷流或追剧，需要按规则自动下载的用户。
- 希望在一个页面查看各站点数据、并在长期未登录之前收到提醒的用户。
- 已经在使用 qBittorrent 或 Transmission，希望统一管理多个下载器的用户。

## 使用前请注意

- pt-tools 使用你自己的账号凭证访问站点。启用自动访问前，请确认各站点的规则允许，并合理设置请求频率。pt-tools 不保证自动化访问不会被站点警告或封禁。
- 数据目录中的 `secret.key` 用来加密站点 Cookie。丢失密钥后，已保存的 Cookie 无法恢复，请与数据库一起备份，见[升级与备份](upgrade.md)。
- 不提供 macOS 二进制；macOS 请使用 Docker 运行。
