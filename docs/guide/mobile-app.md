# 手机 App <Badge type="tip" text="1.0 预览版" />

pt-tools 的手机 App 在外面也能看概览、种子、站点与订阅，并按配对时给的权限暂停、删除、推送种子或管理订阅。App 经[远程访问](remote-access.md)连回 pt-tools：扫网页上的二维码配对，之后先试直连，连不上再走 relay。连接是端到端加密的，relay 只转发，看不到内容。

App 支持 Android（iOS 暂不上架）。界面有中文与英文，跟随手机的语言。

## 安装

Android 安装包和 pt-tools 发布在 [GitHub Releases](https://github.com/sunerpy/pt-tools/releases) 的同一个版本里，App 与服务端版本号相同。安装包按手机的 CPU 架构分开：大多数手机用 `pt-tools-app-arm64-v8a.apk`，较老的 32 位手机用 `pt-tools-app-armeabi-v7a.apk`。下载以后在手机上打开安装，第一次要在系统设置里允许浏览器或文件管理器「安装未知应用」。同一个版本里的 `checksums.txt` 列出了各个文件的 SHA-256，可以用来核对下载是否完整。最早的 `1.0.0-rc.1` 单独发布在 `mobile-v1.0.0-rc.1` 里，之后的版本都可以直接覆盖安装。

版本号带 `-rc` 的是预览版，标为 Pre-release。预览版与正式版用同一把密钥签名，装新版本时直接覆盖安装，已配对的主机都还在；装过 CI 构建的测试包的，要先卸载再装。

## 配对

1. 在 pt-tools 网页上打开「系统 → 远程访问」，确认远程访问已开启，填好直连地址或 relay，见[打开远程访问](remote-access.md#打开远程访问)。
2. 点「添加设备」，选权限（完全控制或只读），生成二维码。二维码 10 分钟内有效，只能用一次。
3. 打开 App，点「扫码」扫这个二维码；也可以把网页上的链接复制到手机，粘贴进「配对链接」。请用 App 里的「扫码」，不要用手机相机或别的扫码 App：二维码里有配对密钥，拿到它就能配对。
4. 填一个设备名（会显示在网页的设备列表里），点「配对」。

配对成功以后网页上的窗口显示「已配对」，App 进入概览。配对窗口过期、用过或者输错太多次时，App 会提示到网页上重新生成二维码。

## 连接

- App 先试配对链接里的直连地址（同一个局域网或从外面能访问时），连不上再按顺序试 relay。现在用的方式与地址在「更多 → 连接与设备」里。
- App 只在前台保持连接：切到后台时断开，回到前台自动重连。连接断了也会自动重连。
- 权限改了（例如从完全控制改成只读）：App 马上重连，按新权限显示。
- 设备在网页上被撤销，或者主机的密钥换了：App 提示「重新配对」，点它回到配对页。
- 网页上关掉了远程访问：App 提示「主机关掉了远程访问」，隔一会儿再试。

## 能做什么

| 页面              | 内容                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| 概览              | 已启用站点的上传、下载（计费）、分享率、魔力、做种与站内信未读，今天的增量，下载器的速度与剩余空间     |
| 种子              | 下载器里的种子，按状态筛选、按标题搜；暂停、继续、删除（删除要确认，可以连同数据一起删）               |
| 搜索              | 在所有启用的站点上搜种子，推送到下载器（照常经过磁盘空间保护与站点做种容量的检查）                     |
| 媒体              | 订阅（进度、缺的集、立即搜索、暂停、删除）、最近入库、探索（热门、流行、搜索，直接订阅）               |
| 更多 → AI 助手    | 和 pt-tools 内置的 AI 助手对话，完全控制的设备能确认改动类操作，见 [AI 助手](assistant.md#在-app-里用) |
| 更多 → 站点       | 登录状态（离封号阈值还有几天）、今天的签到、站点上的用户数据与站内信未读；立即签到                     |
| 更多 → 任务、刷流 | 推送记录，刷流任务的在刷种子与收益                                                                     |
| 更多 → 下载器     | 下载器的速度、剩余空间与版本                                                                           |
| 更多 → 外观       | 四套主题（明亮、暗黑、暖纸、石墨）或跟随系统（浅色用明亮、深色用暗黑），只存在这台手机上               |
| 更多 → 连接与设备 | 连接方式与地址、主机、这台设备的名字与权限；重新连接、忘掉这台主机                                     |

概览与「更多 → 站点」里的下载量都是站点计费的下载量（按免费、折扣折算以后计入分享率），不是实际传输量，见[下载量的两种口径](user-stats.md#下载量的两种口径)。

只读权限的设备看不到写操作（暂停、删除、推送、签到、订阅）。

## 追剧、刷流与统计分享

追剧列表与详情沿用 App 界面，新增、编辑订阅时打开随 App 安装的编辑页，可设置站点、下载器、质量档案、搜索定时、版本锁、起始集与标题包含／排除。保存后返回并刷新列表；有未保存改动时，返回前会询问是否放弃。

「更多 → 刷流」支持新增、编辑、启停与删除任务，并查看运行记录。删除需要确认。配置页只操作刷流任务，不开放整个网页后台的配置权限。

「更多 → 站点」可查看统计和周期增量，并进入统计海报页。海报复用网页的样式、配色与站点选择，用户名、站点名和图标默认打码；每次打开都恢复默认打码。生成后可以保存 PNG 或打开 Android 系统分享面板；取消分享不会自动发送或保存图片。

编辑与海报所需的 Vue 页面已打包进 APK，业务数据仍经原有加密通道从主机获取。App 不会要求网页登录，也不会把设备私钥交给页面。旧服务端未提供相应能力时，App 会提示升级，现有功能仍可继续使用。只读设备可以查看数据、导出海报，不能保存追剧或刷流配置。

内置 AI 助手继续使用主机配置的模型。读取操作直接显示结果，改动类操作先显示待确认卡片，确认后才执行；取消或重复确认不会重复执行。模型没有配置或助手没有开启时，需先在网页上配置。

## 隐私

- App 只和这台 pt-tools 通信：站点图标、TMDB 海报也由 pt-tools 去取再经加密通道传给手机，手机不直接连站点或 TMDB。
- 这台设备的私钥只存在手机的安全存储里（Android Keystore）。「忘掉这台主机」只删手机上的记录，网页上的设备记录不会删除，需要的话在网页上撤销。
- relay 能看到的只有连接的元数据（hostId、IP、时间与流量大小），见[远程访问](remote-access.md#审计与安全)。

## 常见问题

**配对时提示「主机现在没有打开配对窗口」**：二维码过期或者已经用过了，在网页上重新「添加设备」。

**一直显示「正在连接」**：手机连不上直连地址，relay 也连不上。在网页的「系统 → 远程访问」看 relay 是不是「已连上」；在外面用时，直连地址要从外面能访问，或者配一个 relay，见[自己部署 relay](remote-access.md#自己部署-relay)。

**提示「主机的 App API 级别是 …，请升级」**：pt-tools 升级了不兼容的 App API，安装新版本的 App。
